交付判定：尚未具備正式商業交付能力
部署／授權／SDD／MCP 管理歸 VCGC；每個子系統獨立 main。禁止 TA-Lib。此份為差異、架構、風險及隔離測試規格。

判定與證據邊界

目前不具備可宣稱的正式商業交付能力。已有新機引導、環境治理、獨立啟動、原始檔打包、機器／商品識別、部分自測與 Windows CI。缺口集中於可信簽發、權益執行、撤銷、保護後的可重現包、交易式升級回復，以及同一包在全新實體 Windows 的驗收。

本次基準是 2026/11/10 台北時間查得的 main 8fc49fff06fe5860f52a63720f6f98c91f1fda83，合併 PR #624 時間為 12:00:20。PR #621 於 11/09 23:59:01 合併，#622 於 11/10 10:28:06 合併。所有程式碼結論綁定此提交，不代表使用者 PC 的安裝狀態。

需修正 PR #622 的概括說法：倉內已存在 Install-VIA-Product-v0101 的機器／組合號及 MDL256 子系統 ZIP。準確結論是「有部署與識別基礎，但未見完整安全商業授權」，不能說所有商品編號／封裝都不存在。

新機片段所說「只想看計畫就移除 --install」也不成立於整條流程：仍會執行 winget／git、後段 live VDF 及頁面生成。正式 review-only 路線必須是獨立零變更計畫器。

最小可行架構：部署治理歸 VCGC，執行各自獨立

VCGC 保留中央治理、安裝計畫、發行帳本、SDD、MCP 與收據聚合入口。VDF／VRN-2／VQG／VAP 的 main、SSOT、資料庫與健康判斷仍由自己擁有。VCGC 不在執行中，也不能導致已合法授權的 peer 無法啟動。VRN-1 不在本次倉庫範圍。

候選 MVP 次序：先建立離線簽章 token、同機驗權、每產品包與固定樣本驗證；再完成交易式安裝／回復；線上租約及撤銷服務放第二階段。MVP 只承諾有限期離線授權，工程提案上限 30 日；線上 lease 工程提案上限 72 小時。這些是待審商業政策，不是已發給客戶的條款。

候選路徑：%LOCALAPPDATA%\VIA\ReviewCandidates\commercial_v0100\；將來核准的客戶執行包：%LOCALAPPDATA%\VIA\Products\{product}\releases\{release_id}\。資料／log／授權 state 分開；跨使用者 ProgramData 模式與 ACL 另案。預設不依賴 OneDrive、Git 或系統 Python，也不修改全域 PATH／pip。

原始碼保護先評估 Nuitka standalone，將自有核心編譯並明確攜帶 native DLL／資料檔；先驗單資料夾，再評估單檔。現有 glob 尾版、__file__、動態 importlib 與薄尾鏈必須在 build 階段解析成固定清單，不能只編譯最外層入口後偷偷帶入原始 .py。編譯提高逆向成本，不能保證無法還原；PyInstaller 的位元碼封裝也不是原始碼保密保證。簽章證明來源與未被竄改，與隱藏原始碼是不同控制。Nuitka · PyInstaller · SignTool

可驗證產品授權契約

License_Contract_v0100.json 定義語義，schemas/ 提供六份 JSON Schema。Schema 驗證只證明格式；簽章、時間、撤銷、裝置持有證明與發行序號比對都必須額外執行。本包沒有啟用或簽發任何授權。

契約項精確要求
產品序號CSPRNG 128-bit → Base32 26字＋VIA-；issuer ledger 唯一限制。序號不是秘密，也不是授權證明。舊 VIA-C- 組合號只留作別名。
簽章Ed25519；固定 32-byte 公鑰／64-byte 簽章。對 domain separator（含 kind、kid）＋原始 payload bytes 簽署；不得先重新序列化。
資料欄位license_id／customer_ref／device SPKI hash／每產品 features／max_release_sequence／not_before／expires_at／license_sequence／撤銷最低版。
裝置綁定CNG ECDSA P-256 私鑰持有證明；TPM tier 必須可驗，不接受 client 自報即當 TPM。軟體 user key 明示較低保證。
權益判定產品與 feature 精確匹配；版本序號在授權內；VCGC 有效不自動授權 VDF，VDF 過期不連帶停 VRN-2。
時間與重放UTC秒；not_before ≤ now < expires_at；授權／租約／撤銷單調序號；相同序號不同 bytes 拒絕。時鐘回退要求重驗。
離線／撤銷離線人工匯入簽章 token＋有期限撤銷快照。完全離線不可能得知即時撤銷；到期或快照過期不得繼續新付費工作。
線上提案request_id 冪等、單次 activation code、server nonce＋裝置 proof、原子席次帳本；TLS。未設定 endpoint，未啟用任何網路授權。
失效處理不啟動新付費工作；既有工作於安全 checkpoint 結束；保留診斷及既有資料匯出，不刪檔、不加密扣押資料、不殺其他系統。
金鑰生命週期授權、套件、撤銷與 root trust 分角色；TEST／PRODUCTION 分根；換鑰有舊根與新根授權。根失陷需外部核准復原路線。

密碼學使用成熟函式庫與 RFC 8032 測試向量，禁止自行發明加密。Windows 使用者儲存與機器儲存保護範圍不同，DPAPI LocalMachine 不能視作只有一位使用者能解；需明確 ACL／CNG／TPM 測試。Microsoft DPAPI。離線 local-admin 修改、VM 複製及時鐘快照攻擊屬剩餘風險，不能保證絕對防盜版。

風險與控制

級別風險具體原因必備控制
P0誤判安裝成功目前 FreshPC 未逐步 rc gate；舊 installer hash 不符仍往下走必要步驟與功能驗算失敗即 BLOCKED；頁面開啟不是成功。
P0把識別號當授權本機 hash 可重算／JSON 可改，無 issuer 防偽信任公鑰驗簽＋權益／裝置 proof；正式簽發私鑰分離。
P0保護封裝破壞動態載入多代薄尾與 __file__/glob/importlib 路徑依賴先做固定閉包編譯 spike；保留全部實際依賴，禁止隨意刪舊版。
P0共享 runtime／授權造成跨系統故障中央服務不可用拖垮 peer 或一個 token 汙染全家族各自 runtime 與 verifier；隔離 namespace、資料、狀態；停止 VCGC 實測。
P0回復損壞客戶資料備份只含治理冊，不等於 DB／安裝還原copy-on-write migration＋一致性快照＋journal；中斷注入與完整 restore。
P0來源或測試範圍混用舊 HANDOFF GREEN、附件 PASS、LaneCheck READY 被升格固定 SHA／日期／scope；缺資料 UNKNOWN，舊收據 STALE，禁止 scope promotion。
P0TA-Lib 殘留附件 VAP 說明承認仍有 helper不整包導入；掃發行閉包、套件 lock/native 庫並阻擋。
P1離線撤銷與時鐘回復離線無法即時取得撤銷；local admin 可回滾有限期限＋快照 freshness＋人工復原；對外明示剩餘風險。
P1權利／依賴再散布封裝中包含第三方庫、OCR model、字型及資料SBOM＋授權通知＋資料分發範圍審查；未核准內容不入客戶包。
P1MCP 越權與秘密洩漏模型工具可能被誤當安裝器／發號器只讀白名單，去敏 receipt；發行管理不暴露模型工具。

升級與復原契約

提案狀態：DISCOVER → PLAN → APPROVED → STAGED → VERIFIED → COMMITTED → ACCEPTED。每步保存 immutable plan hash／before hash／after hash／退出碼／作用路徑。VERIFY 之前不得啟動下載內容；COMMIT 只切換單一產品的 current pointer，舊 runtime 保留。

若在 COMMIT 前失敗，清除本次 owned staging 即可；切換後功能測試失敗，停止本次所啟動的程序、恢復上次驗證 pointer，再驗舊版。資料升級必用新副本並保留一致性快照，不能把程式降版當作 DB 自動相容。回復不得回退撤銷序號或復活已撤銷授權。簽章 metadata／有效期／序號避免舊版重放，設計參考 TUF metadata；本方案尚未實作或宣稱完整 TUF。

復原驗收：任一 checkpoint 強制中斷後只允許「完整舊版」或「完整新版」，不得混版；核准前的原件／DB hash 不變；復原後既有資料可讀、既有合法權益可驗；另一產品無變更。
