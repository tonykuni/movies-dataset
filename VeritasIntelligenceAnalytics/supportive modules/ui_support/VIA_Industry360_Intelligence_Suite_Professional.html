商業化分析流程

建立 L1/L2/L3 行業分類，鎖定可比較樣本與上下游邊界。

拆客戶別營收、終端需求、ASP、Volume、Mix、訂單能見度與集中度。

拆 BOM、供應商、地區、交期、替代難度、良率、匯率、關稅與物流。

把銷售橋接與成本橋接接到毛利率、EPS、估值、風險與投資結論。

用財報、法說、報價、海關、供應鏈、拆解報告與通路資料交叉驗證。

建立正反情境、觸發條件、回測因子、風控規則與 lesson-learned。

輸出 SSOT：JSON / Parquet / CSV / HTML Dashboard，支援版本追蹤。

同步輸出 Prompt 規範，讓任何 AI 都能接手擴充、驗證與重構。
