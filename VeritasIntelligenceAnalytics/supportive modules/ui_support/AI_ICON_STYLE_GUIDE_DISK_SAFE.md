# VIA Icon Base · AI Icon Style Guide · DISK SAFE

## def Core Rules

def SEO / Business UI 使用 SEO_PNG_ICON_SET_72 或 SEO_PNG_ICON_SET_128。
def VAP 圖型 UI 使用 VAP_CHART_TYPE_SVG_LIBRARY。
def 系統藍色 icon 使用 MATERIAL_SYMBOL_0000F5_36DP。
def 風險紅色 icon 使用 MATERIAL_SYMBOL_EA3323_36DP。
def 同一個 UI 區塊不可混用不同 StylePackId。
