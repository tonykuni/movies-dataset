Story Layer
Zero-Tolerance Report Intelligence

VRN Story

VRN 的起點不是「做一個 PDF 工具」，而是處理接近 0% 容錯率的投資報告解析難題。投資報告裡的數字、表格、圖中資訊、券商觀點、財務欄位與估值假設，任何一處錯誤都會污染後續分析鏈。

因此，VRN 逼出 VIA 的支援模組：加速器讓大型 OCR 與影像處理能跑；網路工具讓資料取得可控；SSOT 讓欄位與語意統一；EnvManager 讓套件與虛擬環境穩定；Registry 與智慧資產管理讓模組不失控。

  • PDF / OCR / Table / Image / Semantic Repair
  • 多源驗證、多方法驗證、SSOT chain
  • 從「讀報告」進化成「還原可信資料結構」
Rapid Enterprise Automation

Veritas Workbench Story

Veritas Workbench 的源起是一個真實職場痛點：PM 工作、PLM 導入、既有 SAP、MS Project 與每週一簡報壓力交疊。它不是取代舊系統，而是尊重既有系統，讓新系統負責同步、對標、治理與自動化。

Workbench 開發速度快，不是因為需求簡單，而是因為 VIA 已提前完成底層能力：VRN 能讀文字、表格與圖中資訊；VDF 能建資料庫與驗證；VAP 能輸出矩陣與圖表；SSOT / Prompt / Methodology 能讓 AI 輸出可控。

  • PLM · Project Management · Auto-SSOT · Process Mining
  • Email / Attachment / SAP Export / MS Project / PLM 對標
  • 週報、Pivot、固定圖表、簡報草稿、人機校正回寫

Veritas Workbench 工作流程 / Human-in-the-loop Automation

Workbench 不是一鍵生成結論，而是可審計的人機協作流程：先抽取與結構化，再由人檢查觀點，最後才生成週報與簡報。

Workflow
Step 01

人啟動系統

Authorized Start

使用者指定授權資料範圍、專案、週報週期與輸出模板。

Step 02

資料擷取

Email / SAP / PLM / MS Project

只處理授權資料，保留來源、時間戳、權限與審計紀錄。

Step 03

VRN 解析

Text / Table / Image

文字修復、表格還原、圖中資訊辨識、附件分類與去重。

Step 04

Auto-SSOT

Keyword / Alias / Mapping

把行話、縮寫、欄位與系統代碼對標到可治理的真相源。

Step 05

Process Mining

Workflow Discovery

還原流程、找瓶頸、建立責任矩陣、遺漏清單與風險燈號。

Step 06

人類校正

Checkpoint

系統列出觀點與可能錯誤，人類確認後才進入簡報生成。

Step 07

週報生成

Report + Learning

生成週報、Pivot、圖表、簡報草稿，並把修正回寫知識帳本。
