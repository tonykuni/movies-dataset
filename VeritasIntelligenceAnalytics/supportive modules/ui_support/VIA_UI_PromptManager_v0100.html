🟥《PowerShell 指令語法多輪並行安全修正引擎:專用 Mega-Prompt》
(Multi-Round AST-Anchored PowerShell Syntax Auto-Repair Engine)

【中文版】啟動「PowerShell 指令語法多輪並行安全修正引擎」,調用全套語法診斷工具與 AST 雙模錨點定位機制,對所有 PowerShell 腳本/模組/指令檔執行多輪「全景式語法分析、錯誤分流、並行安全修正、沙盒啟動驗證」直到啟動測試完全無誤。
核心原則:①全景式分析先行(PSScriptAnalyzer+AST Parser+Command Inspector)②AST 雙模錨點(精準 Extent 座標/彈性結構簽名)③Zero-Hydra 零九頭龍風險④Parallel-Fixable 一口氣並行修正、Sequence-Dependent 循序拓撲⑤每輪沙盒 Dry-Run 閉環。
三輪:R1 全景掃描+並行修正/R2 依賴拓撲循序修正/R3 收尾優化(死碼/編碼統一/try-catch 強化)+非阻塞啟動測試。
輸出:自適應 HTML UI 矩陣(小字體/自動換行/RYG 燈/MODULE·ENGINE·FUNCTION-LIB·OTHERS 四專區/修正前後對比/Hydra 風險預測/沙盒驗證日誌)。

[English] Activate the "PowerShell Multi-Round AST Auto-Repair Engine". Panoramic analysis first (PSScriptAnalyzer + AST Parser + Command & Parameter Inspector); dual-mode AST anchoring (Precision line/column vs Elastic structural signature); Zero-Hydra Protocol; comprehensive parallel repair of Parallel-Fixable errors in Round 1, topological order for Sequence-Dependent; sandbox dry-run loop each round until flawless launch. Round 3 polishing: dead code elimination, encoding unification, try-catch hardening, non-blocking launch test. Output: auto-wrapping small-font HTML RYG matrix across MODULE / ENGINE / FUNCTION-LIB / OTHERS zones with before/after and Hydra-risk matrices.
