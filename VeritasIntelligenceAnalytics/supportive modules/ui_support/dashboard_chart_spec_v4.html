5軸與資料規則

項目規則
左右軸刻度間距值皆為 2 / 2.5 / 5 / 10 的倍數(nice ticks);左右間隔數相同→格線對齊;小數位依間距統一;千位數加千分位號。
軸範圍包覆資料 min/max;上方自動留一格給圖示(避免與線重疊)。
時間軸交易日序軸:左右軸雙方皆無資料的日期(週末/假日)整列移除→無日曆空隙;從上到下全面板一致。
缺值處理聯集日期→全空日刪除→缺資料者取前一交易日的值(前值填補);量不前值填補。
垂直線2025上半年高 / 2025低 / 2026-01-02 / 2026高 / 目前,貫穿全部面板+圖①頂端標籤;標最大拉回% 與 高→低 歷時(日/交易日)。
標題/圖示標題僅標左右軸(不換行、不標圖型);圖示=完整名稱 (Ticker/ID);指數單位統一「(指數)」。
