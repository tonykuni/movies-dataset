操作邊界

儀表板由 Python 單檔生成；HTML 使用內嵌 CSS/JavaScript，可用 file:// 開啟。沒有 server、fetch、WebSocket、CDN 或遠端套件。VCGC 沒有 repo／已驗證 mount 時維持未連接狀態。

資料來源為產生當下的本機快照。Token estimator 僅供趨勢觀察；正式節省率以相同任務與模型的實際 usage、品質與延遲回歸測試為準。
