# VRN 檔名、首頁與年度財報整合規格 v0.2.0

本版依本次指示增補；現有字庫、差異映射與歷史規則全部保留。GitHub `movies-dataset` 維持唯讀。本包新增可測試的核心函式與接線契約，沒有宣稱已啟動現役 PDF／OCR 或官方財報下載流程。

## 1. 公司身份與名稱

主鍵是四碼股票代號。公司／證券名稱由 TWSE、TPEx、MOPS 官方主檔取得，分欄保存「證券簡稱」「公司全名」「英文名稱」「市場」「資料日期」「來源網址」。檔名與報告中的公司寫法保留作證據，不能覆蓋官方名稱。

KY 公司不另行判錯或改名；官方記錄有 `-KY`、外國公司標記或其他合法字樣便原樣保留。全名與簡稱不同不是衝突；比較時要對同一語意欄位。多個官方來源在同一欄位出現不一致，保留全部值，核對資料日期、改名及市場變更。

官方來源入口：[TWSE 公司主檔 API](https://openapi.twse.com.tw/v1/opendata/t187ap03_L)、[TWSE OpenAPI 規格](https://openapi.twse.com.tw/v1/swagger.json)、[TPEx](https://www.tpex.org.tw/)、[MOPS](https://mops.twse.com.tw/)。本輪確認來源入口，未大量下載公司或年度財務資料。`official_company()` 消費上游傳入的官方標準化記錄，查不到回 `OFFICIAL_LOOKUP_REQUIRED`。

## 2. 檔名拆解與交叉核對

順序固定為：保留原檔名 → 保護完整日期／三平台代碼／ETF／季度／KY 名稱片段 → 剩餘部分依連續中文、英文、數字、標點交界切開 → TRIM → 提取候選 → 主檔與首頁核對。

| 輸入 | 判讀 |
|---|---|
| `3038` | 四碼股票候選，須查主檔／核對首頁 |
| `2330.TW`、`2330 TT`、檔名 `2330TT` | 提出本地碼 2330；保留原平台寫法 |
| `2026年展望` | 年份／代碼歧義，不直接當股票；也不永久禁止 20xx 作股票候選 |
| `20250122` | 西元 2025/01/22 |
| `1140122` | 民國 114 年，即 2025/01/22 |
| `250122`、`(20)250122` | 在研報年月日語境解析為 2025/01/22 |
| `CTBC0915` | 月日 09/15，年份缺失；不補當年 |
| `926708` | 不合法日期，保留未分類數字 |
| `006208` | ETF 格式候選，不因六碼而當日期 |

股票要求 FILENAME 與首頁其他平台代碼的四碼本地碼完全一致，並核對 `.TW`／`.TWO` 所代表的市場。Bloomberg 的 `TT` 無法單獨證明上市或上櫃。ETF 比對完整本地碼與尾碼，不能只比前四碼。

只取得一邊回 `INSUFFICIENT_EVIDENCE`；不同回 `MISMATCH`；本地碼相同但市場不符回 `MARKET_MISMATCH`。不可把「格式正確」直接算成「公司身份已確認」。輸出日期顯示 `YYYY/MM/DD`；內部比對使用 ISO `YYYY-MM-DD`。

券商允許檔名局部識別：`華南投顧` 可命中已登錄的 `華南`，`兆豐個股報告` 可命中 `兆豐`。優先長別名；英文短碼保留字母邊界；官方公司名或代碼後面的公司片段先排除。`凱基投顧_2891 中信金_…` 的券商應為凱基，不能被中信金誤導。未核實的 GFHK 保留候選字詞，不只憑 GF 前綴指定券商。

## 3. 首頁版面、文字修復與語意記錄

原始文字層／OCR 輸出須保留 `page、bbox、block_id、column_id、font_size、bold、reading_order、raw_text、source_id`。Layout adapter 先識別頁首、左資訊區、右資訊區、正文、表格、註腳；後續分類保留版面證據。

大／中／小標題以相對字級、粗細、位置、行距、與公司名稱／代碼的鄰接關係共同判定。通常標題沒有句點，但「沒有句點」不能單獨決定是標題；有句點的大標題也不能因此丟棄。公司名稱與代碼後方、字級相近的句子是首頁主標題的重要候選。

修復只能在同頁、同欄、同區塊與相容角色內進行。先修復換行、中文斷句與多餘空白，再 TRIM，保留每次修復記錄與原文位置；不得跨欄將左右資訊拼成一句。不能改掉小數點、負號、括號負值、百分比、年份、單位或基本／稀釋 EPS 標示。

修復後輸出一筆句子或一筆欄位資料，標示角色與來源。英文縮寫與小數點交給具語境能力的 NLP adapter 判句，不以每個點號切割。本包核心只安全切分中文句末標點，尚未接入完整 NLP 模型。

頁尾、後方備註的小字只有在與研究資料無關時才排除摘要。若含目標價、評等、日期、幣別、單位、稀釋 EPS 或財報註記，仍必須保留。原頁與原文字都不刪除。

## 4. 目標價、評等與評價方法字庫

新增 64 筆帶來源與條件的記錄：目標價 9、評等 21、評等欄標籤 7、評價方法 20、EPS 概念 7。這是新增記錄數，部分拼法已存在於其他來源，因此不宣稱全部都是全新字詞。

| 類別 | 本次補充例子 | 條件 |
|---|---|---|
| 目標價 | 目標價格、股價目標、十二個月目標價、12M Target Price、12-month Price Target、Fair Value Estimate、合理價值 | 必須有價格／每股／幣別語境；排除百分比、倍數、市場規模 |
| 買進 | B、Buy rating、買進評等、推薦買進、超配 | 單字母只在券商已識別的評等欄使用 |
| 持有 | H、Hold rating、Equal-weight、Equalweight、Market Weight、持平、標準配置 | 保留原券商尺度 |
| 賣出 | S、Sell rating、低配、建議減碼 | 不能把交易方向或動作直接當評等 |
| 未評等 | Unrated、Not Covered、No Recommendation、不予評等、尚未評級 | 覆蓋狀態另存；不把 Note 自動歸入 |
| 欄標籤 | 投資評等、投資評級、投資建議、Investment Rating、Recommendation | 標籤不等於評等值 |
| 評價方法 | P/E、P/B、EV/EBITDA、DCF、SOTP、Dividend Yield 及中文別名 | 同時擷取採用年度、輸入值、公式、假設與理由 |
| EPS | 稀釋每股盈餘／Diluted EPS、基本每股盈餘／Basic EPS | 兩種概念分開，不互補替代 |

前版的差異也繼續保留：`Accumulate → BUY／ADD`、Strong Buy 的粗／細分類等依來源解析，不因新增詞而覆蓋。目標價的前次／本次、Base／Bull／Bear 情境分欄；一份報告同時有數個價格時不得直接取最大值。

## 5. 首頁四點摘要契約

標頭固定：**官方證券名称(已核對的 Yahoo 代碼)-首頁主標題**。例如格式為 `台積電(2330.TW)-本文標題`，其中實際名稱仍取官方主檔。

| 點次 | 必要內容 |
|---|---|
| 1 | 評等、目標價、最新調整後收盤價與日期、上漲空間；使用的評價方法、年度、參數、邏輯與理由 |
| 2 | 稀釋 EPS、所屬年度、實績／預估、成長性與原因；沒有 Diluted EPS 就明示未揭露 |
| 3 | 首頁剩餘的主要營運動能、產品／訂單／產業亮點 |
| 4 | 首頁剩餘的催化因素、風險、限制條件與其他重要內容 |

報告敘述只來自第一頁，每句連回 source_id。年度財報頁的資料不能補進「首頁摘要」冒充首頁已說明；可另在財務資料表展示。最新調整後收盤價是外部計算輸入，清楚標成 `DERIVED` 與價格日期。資料不足時保留四點結構，該點標示未揭露，不湊句子。

上漲空間：`(同口徑目標價 ÷ 最新調整後收盤價 − 1) × 100%`。

目標價與價格必須同幣別、同每股基準及可比的調整基準。已知拆股或每股換算可先對齊並留下轉換記錄；不能把含現金股利的 Adj Close／Close 比值直接套到目標價。若口徑無法確認，保留兩個原值，回 `BASIS_MISMATCH` 而不產生混用結果。歷史報告的當時上漲空間與本次要求的最新上漲空間分欄，避免回測使用未來資料。

## 6. 年度財報全頁擷取與核驗

先找出所有年度財務頁，再依 layout 掃描每頁上／下／左／右區域；多個表格分別保留，不能找到一張表就結束。保存年度欄頭、Actual／Estimate、科目、數值、單位、幣別、合併／個體、註脚、來源頁碼及儲存格位置。

每格的核對鍵為：`股票代號 + 年度/期間 + 科目概念 + 合併/個體 + 幣別 + 單位 + 會計基準`。歷史實績再比 TWSE／TPEx／MOPS 官方數值；標準化單位後才比大小。

一筆語意鍵完整、有來源且不只是共同零值的歷史實績對上，可記為「對齊錨點」。**這只確認該對照，不能宣告整張表皆正確或沒有漏表。**其他格仍逐筆比；完整性另外以預期頁／區域／表／列／格數核驗。

歷史實績兩邊都有時，同口徑官方資料作 canonical value；報告原值、差額、修訂日期完整保留。報告預估不被歷史資料覆蓋；最新視圖可採重編後官方歷史值，歷史回測則限制公告日不晚於當時日期。

| 驗證 | 必須先確認 |
|---|---|
| 資產 = 負債 + 權益 | 同日期、同合併口徑；使用總權益，不能漏非控制權益 |
| 營收 − 成本 = 毛利 | 同期間、相同單位 |
| 利潤 ÷ 營收 = 利潤率 | 毛利／營業利益／淨利分開，百分比一致 |
| 稀釋 EPS = 稀釋後盈餘分子 ÷ 加權平均稀釋股數 | 使用調整後分子及加權股數，不能拿期末股數代替 |
| 年度 = 季度合計 | 只用可加總流量科目；不得加總 EPS、比率、資產負債表時點數據 |
| 成長率 | 同期間、幣別、單位與會計口徑；基期為零或負數時另外標註解讀限制 |

零、空白、橫線缺值分開。四捨五入容差可設定，核心預設絕對 0.01／相對 0.5%，正式使用應依每股、金額與百分比各自設定。加減除核驗只是內部一致性證據，不能代替來源驗證。

本輪：原 30 項檢查通過；新增 48 項合成測試通過，含 AST／compile／import。106 個原始檔名測試仍保留。已驗證每筆前版同義字記錄均存在於新版。
