# VAP v2.3 圖庫與堆疊編輯器規格

## 1. 本版目標與狀態

v2.3 把原本「直接把表單追加到圖組」的操作，整理成可重用、可重排的工作流：

```text
擷取資料來源 → 設計／預覽單圖 → 存入 VAP 圖庫
                                      ↓
                         搜尋圖庫 → 加入堆疊 → 拖曳排序 → 輸出
```

本文件使用以下狀態，避免把構想誤寫成已完成：

| 狀態 | 意義 |
| --- | --- |
| **v2.3 已實作** | 本版的介面或 renderer 契約 |
| **下一階段建議** | 已設計優先級，但不代表目前可以操作 |

v2.3 已實作的核心範圍：

- 單圖完成後可存入本機 VAP 圖庫，圖庫可搜尋並加入目前堆疊。
- 左側資料來源與右側規格面板可收合；右側以「左軸／右軸」樹狀分組呈現。
- 堆疊項目可用滑鼠上下拖曳；保留按鈕式排序作為精確操作方式。
- 標準圖高為 420 px，邏輯單圖的高度使用標準高度倍數。
- Candlestick + Volume 是一個邏輯圖表、兩個上下排列的實體單軸 panel；高度比例為 75% / 25%，共享 X 時間軸。
- Plotly HTML、300 DPI PNG 與 PDF 沿用同一張圖的順序、相對高度、顏色與軸契約。

## 2. 與既有 VAP 紀錄的對照

v2.3 並非改掉既有 VAP 思路，而是將先前紀錄中分散的要求收斂成一條一致流程。

| 既有 VAP 要求 | v2.3 決定 |
| --- | --- |
| 單圖做好後再向下加圖 | 單圖可先存入圖庫，再由圖庫加入 `charts[]` 最下方 |
| 左面板要精簡、可收合 | 左側只放來源選取、掃描、狀態與必要欄位；詳細結果按需展開 |
| 左右軸要容易理解 | 右側以樹狀「一般／左軸／右軸／進階」分組，不把所有欄位平鋪 |
| 堆疊要能調整順序 | 清單支援滑鼠垂直拖曳，輸出順序與畫面順序一致 |
| 圖高應有標準尺寸與倍數 | 420 px 為 `1.0×`，每張邏輯單圖以倍數決定高度 |
| 圖組共用日期軸 | 邏輯圖及其實體子 panel 共享 X；上方可省略重複的日期標籤 |
| K 線與量要連動但不能混軸 | K 線與 Volume 分成 75% / 25% 兩列，各自只有單一 Y 軸 |
| 左右軸間隔數一致 | 雙軸預設各 5 個 tick、4 個區間；同 tick 數，不強迫不同單位用同一數值步距 |
| 價格與量的缺值不能同樣處理 | adjusted price 可 ffill；Volume 不 ffill、不 interpolate、也不補零 |
| 台股紅漲綠跌 | K 線及對應 Volume 使用同一根資料列的紅／綠方向色 |

## 3. 編輯器版面

### 3.1 左側：資料來源

左面板負責「資料從哪裡來」，不混入視覺參數。主要操作為：

- 選擇 CSV／TSV、Parquet、Excel、JSON／JSONL、SQLite、DuckDB 或 SQLAlchemy URL。
- 列出 table、view、Sheet 或資料集 partition。
- 掃描欄位的 declared type、Pandas dtype、語意型別、單位、空值、唯一值與範圍。
- 將分析出的欄位填入單圖表單，仍允許使用者修正。
- 收合時只保留來源名稱與目前 table／Sheet 摘要，騰出單圖預覽空間。

資料掃描不修改來源；資料庫使用唯讀路徑，遠端 SQL 僅允許讀取查詢。

### 3.2 中央：單圖、圖庫與堆疊

中央工作區分三個連續動作：

1. **單圖**：以目前來源與欄位設計一張圖，確認圖型、軸、顏色、高度與缺值規則。
2. **圖庫**：將目前單圖規格保存成可重用項目；使用名稱或搜尋條件找到後加入圖組。
3. **堆疊**：顯示實際輸出順序；拖曳項目即可上下重排，新增項目預設放在最下方。

圖庫保存圖表規格與所需欄位，不複製來源資料。從圖庫加入圖組時會建立新的圖表 ID，因此之後調整該堆疊項目，不會修改圖庫原件。

圖庫搜尋至少涵蓋：

- 圖庫名稱與圖表標題。
- 圖型，例如 `line`、`dual`、`candlestick`、`stacked_area`。
- 標籤。
- X、Y、右軸、OHLCV 等欄位名稱。

### 3.3 右側：樹狀規格

右面板可整體收合；展開後以樹狀節點降低一次看到的控制數量。

| 節點 | 常用控制 |
| --- | --- |
| 一般 | 標題、圖型、palette、標準高度倍數、圖例、normalized series |
| 左軸 | 欄位、圖型、名稱、單位、格式、零軸策略、線寬、透明度 |
| 右軸 | 啟用勾選、欄位、`line`／`bar`／`area`、名稱、單位、格式、線寬、透明度 |
| K 線 | adjusted O／H／L／C、Volume、紅漲綠跌色、K 棒寬度 |
| 品質 | 日期無效值、重複日期、缺值、極端值的稽核與 render-copy 修正 |
| 進階 | tick policy、tick count、日期 tick 上限、stack mode、heatmap 設定 |

常用控制使用唯讀下拉或勾選，避免自由文字造成錯字；需要連續數值的線寬、透明度與柱寬仍可直接修改。按「回復預設」時只回復目前節點，不應意外清掉其他節點。

## 4. 標準高度契約

### 4.1 邏輯高度

標準圖高：

```text
STANDARD_CHART_HEIGHT_PX = 420
邏輯圖高 = 420 × height multiple
```

UI 使用「標準高度倍數」稱呼；設定檔沿用 `height_ratio` 以維持 v2.2 相容。合法範圍為 `0.25×` 至 `4.0×`，以 `0.25×` 為步進；常用下拉選項包括 `0.5×`、`0.75×`、`1.0×`、`1.25×`、`1.5×`、`2.0×`。

| 倍數 | HTML 邏輯高度 | 適合用途 |
| ---: | ---: | --- |
| 0.5× | 210 px | 簡單量圖、事件帶、單一指標 |
| 0.75× | 315 px | 成交量、簡單柱圖 |
| 1.0× | 420 px | 一般折線、面積、單軸圖 |
| 1.5× | 630 px | K 線、雙軸或 series 較多的圖 |
| 2.0× | 840 px | 熱圖、需要較多標註的圖 |

### 4.2 Candlestick + Volume 高度

Candlestick 保持一個圖庫項目與一個邏輯圖表 ID，但 renderer 展開成兩列：

| 實體 panel | 高度 | Y 軸 | 資料 |
| --- | ---: | --- | --- |
| K 線 | 邏輯圖高的 75% | 單一價格軸 | adjusted Open／High／Low／Close |
| Volume | 邏輯圖高的 25% | 單一成交量軸 | Volume，不補值 |

兩列共享 X 時間軸。兩列之間不使用 `twinx` 或 Plotly secondary Y；Volume 的量級不會壓縮 K 線價格波動。

若邏輯高度為 `1.0×`，K 線與量約為 315 px／105 px；若為 `1.5×`，則約為 472.5 px／157.5 px。實際像素可由 renderer 取整，但總高度與 75% / 25% 比例必須保持一致。

## 5. 軸與刻度契約

### 5.1 雙軸

一般雙軸圖仍可把左軸與右軸放在同一 panel。預設：

- 左右軸各 5 個 major ticks，即 4 個等距區間。
- 左右軸的區間數相同，但價格、百分比、成交量等不同單位各自選步距。
- 範圍必須包住有效資料最大值與最小值，並在此限制下盡量緊，最大化可見波動。
- 柱圖可依零軸策略包含 0；價格預設不強迫從 0 起算。

### 5.2 合法步距

既有 VAP nice-step 家族為 `2、2.5、5 × 10^n`；本專案依使用者指定保留 `1.25 × 10^n`。因此鎖定刻度使用：

```text
1.25、2、2.5、5 × 10^n
```

`10 × 10^n` 等同下一個數量級，可作為跨級結果。格式器依步距保留必要的小數位與尾零，例如同一軸顯示 `1.25`、`2.50`，不把 `2.50` 簡化成 `2.5`。

## 6. 圖型與資料規則

### 6.1 K 線與 Volume

- OHLC 欄位視為已調整價格；不以 raw close 比例重算 adjusted OHLC。
- `close >= open` 為紅漲，`close < open` 為綠跌。
- Volume 柱沿用同一列 K 線方向色，預設透明度 `0.75`。
- 價格缺值可從前一個有效交易日 ffill。
- Volume 不得 ffill、interpolate 或 zero-fill；缺值保持缺值。
- 不新增週末或休市日；只在來源已存在的時間列中處理價格缺值。

### 6.2 線、柱與面積

- 線寬預設 `1.65`，左右軸可分別修改。
- 柱圖透明度預設 `0.75`；柱寬盡量填滿相鄰 X 間隔，但不得交疊。
- 線下面積透明度預設 `0.50`。
- Seaborn palette 同時提供 Plotly 與 Matplotlib 顏色，避免 HTML 與 PNG／PDF 配色不一致。
- `normalized_y` 在 Plotly HTML 預設半隱藏，使用者可在圖例勾選後顯示；其隱藏軸不影響主軸範圍。

## 7. 輸出契約

| 格式 | 契約 |
| --- | --- |
| HTML | 自包含 Plotly，離線開啟；保留 hover、縮放、series 開關與 normalized 勾選 |
| PNG | 300 DPI 高畫質輸出；順序、高度比例、軸與顏色須和 HTML 一致 |
| PDF | 向量輸出；生成後需確認檔案存在且可開啟，不能只顯示成功訊息卻沒有檔案 |

一般線圖、雙軸圖、K 線、量圖與 stacked bar／area 都使用同一套垂直堆疊版面模型。只有互動控制屬於 HTML；PNG 與 PDF 不假裝提供勾選或拖曳。

## 8. 下一階段堆疊編輯功能建議

以下皆為 **下一階段建議，v2.3 不應宣稱已完成**。

### P0：優先補齊安全編輯

| 功能 | 使用價值 | 建議行為 |
| --- | --- | --- |
| Undo／Redo | 拖錯順序或批次修改後可立即復原 | 記錄新增、刪除、拖曳、覆寫與批次套用，不記錄純預覽 |
| 啟用／停用 panel | 暫時比較不同組合，不必刪除圖 | 停用項目保留在清單但不輸出，外觀半透明 |
| 鎖定共享 X 範圍 | 不同圖以完全相同日期窗比較 | 支援自動、全圖組鎖定、單圖例外三種狀態 |
| 資料欄位相容檢查 | 換資料來源或從圖庫加入時先發現缺欄 | 在加入前列出缺少、型別不合與可替代欄位，不靜默改圖 |
| 指定 panel 輸出 | 只匯出選定研究圖，不必複製整個專案 | 支援單一或多選，仍保持選取項目的相對順序 |

### P1：提高大量編輯效率

| 功能 | 使用價值 | 建議行為 |
| --- | --- | --- |
| 多選批次套用 | 一次統一 palette、高度、刻度、線寬與透明度 | 套用前顯示影響項目與差異摘要 |
| 群組與收合 | 長圖組可依價格、籌碼、基本面分類 | 群組只影響編輯器顯示；輸出可選擇是否加群組標題 |
| 圖庫模板版本 | 調整共用模板時保留舊研究重現性 | 堆疊項目記錄引用版本；升級要由使用者確認 |
| 複製／變體 | 以既有 panel 快速做不同欄位或期間比較 | 產生新 ID，標題自動標示「副本」且可立即改名 |
| 快速對齊 | 修正不同圖的圖例、零線、邊距與日期 tick | 只對同類參數操作，不覆寫資料欄位 |

### P2：進階研究工作流

| 功能 | 使用價值 | 建議行為 |
| --- | --- | --- |
| Linked crosshair／brush | HTML 中跨 panel 對齊同一日期 | hover 與選取區間同步，靜態輸出不模擬互動 |
| 事件線與區間帶 | 標記財報、除權息、政策與交易事件 | 事件層與資料 series 分離，可全圖組或指定 panel 顯示 |
| 圖組快照與差異 | 比較前後版本、資料來源與參數差異 | 顯示新增／刪除／移動與欄位、軸、樣式變更 |
| 條件式警示標記 | 在突破、量增或品質異常時高亮 | 規則必須可檢查，不能只以視覺猜測 |
| 可存取性檢查 | 降低色盲與低對比問題 | 檢查顏色差異、字級、線型替代與 PDF 可讀性 |

## 9. v2.3.1 驗收清單

v2.3.1 發佈前至少確認：

- 左資料源與右規格面板可收合及重新展開，值不遺失。
- 右軸未啟用時不顯示無效控制；啟用後能完整修改欄位、圖型、單位、格式、線寬與透明度。
- 單圖可存入圖庫，可被搜尋，加入圖組後獲得獨立 ID。
- 拖曳後 `charts[]` 順序與 HTML、PNG、PDF 的由上到下順序相同。
- `1.0×` 圖高對應 420 px；其他倍數正確累加。
- Candlestick 實際展開成 K 線與 Volume 兩個單軸 row，比例 75% / 25%，共享 X。
- K 線／Volume 紅綠色逐列相同；price ffill 不污染 Volume。
- 雙軸均為 5 ticks／4 intervals，範圍包住資料，合法步距包含 `1.25、2、2.5、5 × 10^n`。
- HTML 可離線開啟；PNG 為 300 DPI；PDF 檔案存在、非空且可正常開啟。
- 大型資料超過渲染上限時會使用可重現的圖型感知縮減，並在 audit 明列方法、完整列數與實際渲染列數。
- 多實例同時寫 config、圖庫與輸出時不產生半成品或遺失已提交項目。
