# 年度財報左右及上下分表修正 v0103

2026-09-27。針對使用者指出的晶心科 CTBC 第 5 頁：左右財報及上下財報被黏成 70×10 大表，科目名稱和數字亦分成不同列。

## 原因及修正

- 舊分表只辨識「表一／Table 1」等編號表題與相同表頭，沒有把「資產負債表／損益表／現金流量表／比率分析」當成各自獨立的表。
- 原頁科目與數字基線相差約 3.1 點，超過舊行聚類容忍值；投影模板因而缺少完整科目欄。
- 新版先以獨立財報名稱及鄰近年度表頭證明欄位，再依每一欄自己的後續表題界定上下邊界。切線由實際座標求得，不固定對半，也不要求左右下方表題同高。
- 表內使用字框高度對齊基線，同欄垂直堆疊的文字不得誤合併。科目欄右界由數值欄實際起點界定，保留 EPS 的括號與單位。
- 每張表有自己的表題、年度、列、來源與 ID；獨立財報不得再橫向接回或跨頁錯併。HTML 左右各成獨立欄，欄內上下各自顯示表格卡片；窄螢幕改成單欄。
