# AUTO SSOT · 銷售作戰卡（台達電 Delta / 康舒 AcBel）

_對象都是電源硬體大廠：EVT→DVT→PVT→MP、BOM、ECN、SAP、MS Project、全球供應鏈。主打能力「AUTO SSOT」，不主打尚未定案的品牌名。live demo 打贏話術。_

---

## 一、對象速寫（開場能講出他們的世界＝先贏一半）

- **康舒 AcBel（6282）**：金仁寶集團旗下、全球前十大電源廠，三大事業（電源／智慧綠能／電動車電控），近期切入 AI 伺服器電源（33kW PowerShelf）。客戶含 HP／Lenovo 等一級大廠。
- **台達電 Delta**：橫跨零組件電源與散熱、電動車、資料中心、工業／樓宇自動化、能源基礎設施的巨型集團。

**共同痛點（你開場就點破）：** 多產品線並行、跨廠跨客戶、EVT→MP 之間規格變更頻繁，「**為什麼改**」常在信件與電話裡，SAP 只留結果、MS Project 只留劇本——出事時翻信箱翻到崩潰。

---

## 二、五大致勝主軸（Win Themes，依重要性排序）

1. **資料主權（最強解鎖點）**：客戶 BOM、HP/Lenovo NDA、EV IP 絕不敢丟公有雲 AI。我們**100% 本機、唯讀、你的帳號、什麼都不外傳**——資安長能放行、IT 可稽核。這一條讓對手的雲端方案直接出局。
2. **AUTO SSOT 免組態**：不必告訴系統「我們是電源業」，插上就自動編碼、分類、對齊。滑鼠三回合現場就跑。
3. **還原「為什麼改」**：把 SAP ECN（改了什麼）＋ MS Project（排程）＋ 郵件（為什麼＝客戶電話要求降溫）用料號串起來——**這是 SAP/MSP 單獨做不到、也是他們每天的痛**。
4. **不可遺漏（工程師才信）**：完整性 gate「寧可 FAIL 也不假裝完整」，每個缺口都有原因。給工程主管客觀鐵證的安全感。
5. **流程探勘卡點**：多專案並行，一句「你們 DVT→PVT 平均卡 8.7 天、某案返工 2 次」直接命中他們的日常，數字自己說話。

## 三、10 分鐘 live demo 腳本（那個「哇」的瞬間）

> 用**他們給的一小份去識別樣本**（或我方電源業 demo 包）：SAP MM 採購匯出 + MS Project XML + PLM ECN + 幾封信。

1. **[0–1 分] 什麼都不設定** — 把檔案拖進去，「我不告訴它你們是電源業，也不填任何欄位對照。」
2. **[1–3 分] 自舉＋編碼** — 它自己發現階段桶（EVT/DVT/PVT/MP）、每筆自動鑄碼，**原始單號原封不動**（指給他們看 PO/UID 沒被改）。
3. **[3–5 分] 完整性** — 秀「看到 N 筆、擷取 N 筆、失敗都有原因、未解釋遺漏＝0」。**「這個數字你敢給老闆看。」**
4. **[5–8 分] 還原決策鏈（王牌）** — 「料號 PN-PSU-500：MS Project 顯示 DVT 卡住 60%，SAP 顯示 ECN 改銅質散熱片，**但為什麼改？**」→ 系統從信件撈出「客戶電話要求降溫」。**停頓，看他們反應。** 「SAP 和你們的 MS Project，找得到這句話嗎？」
5. **[8–10 分] 流程圖＋卡點** — 秀流程探勘 SVG：主幹路徑、紅色卡點、返工環、偷跑。「這是你們真實走過的路，不是理想劇本。」

**收尾一句：** 「全程本機、沒連任何雲、我剛剛沒填任何設定。這台電腦拔網路線一樣跑。」

## 四、異議處理（Objection Handling）

| 他們會說 | 你這樣回 |
|---------|---------|
| 「我們已經有 SAP／PLM 了」 | 我們不取代它，我們是**把三套系統的『為什麼』串起來的那層**，唯讀、本機，不動你的 SAP。 |
| 「資安過不了」 | 100% 本機、唯讀、用你自己的帳號、什麼都不外傳；IT 可全程稽核。這正是我們的設計核心。 |
| 「導入要多久」 | 滑鼠三回合現場就跑，試點先做 1 個月、單一資料夾，確認流程對再全量。 |
| 「沒聽過你們／新公司」 | 你買的是**能力不是品牌**——剛剛的 demo 就是答案。給我 1 個月 POC，資料全留你手上。 |
| 「沒有 AI 會不會唬爛」 | 全是確定性規則、斷網也跑，完整性 gate **寧可 FAIL 也不假裝完整**——反而比黑箱 AI 可信。 |
| 「跨部門政治敏感」 | 卡點顯示可套柔性辭典（>5 天顯示『決策熟成中』而非點名），數字客觀但給高管顏面。 |

## 五、關於「名字沒定」——把它變優勢

- **主打能力詞**：全程講 **「AUTO SSOT 引擎」**，這是他們沒聽別家講過、一聽就懂的差異化。名字次要。
- 被問產品名：給工作名（VIS Workbench）即可，強調「命名還在收斂，因為我們讓客戶的實際使用來定義它」——反而顯得謙遜且以客為尊。
- **系統用詞先鎖三個**（現場一致就夠專業）：`AUTO SSOT`（自動單一真實來源）、`完整性 gate`（不可遺漏）、`決策鏈還原`（為什麼改）。三個詞講到底，比一堆術語更有記憶點。

---

## 六、致勝關鍵動作（提高勝率的槓桿）

1. **POC 而非簡報**：主動提「1 個月、你們的資料、你們的機器、什麼都不帶走」——把資安顧慮變成賣點。
2. **完整性數字當信任錨**：工程主管吃這套，開場就秀「未解釋遺漏＝0」。
3. **王牌只打一次、打在第 5 分鐘**：決策鏈還原那句「SAP 找得到這句話嗎」，停頓，讓沉默替你成交。
4. **針對康舒**：強調 AI 伺服器電源＋EV 兩條線並行、變更多，AUTO SSOT 幫他們把並行專案的變更脈絡收斂。
5. **針對台達**：強調事業體極多、系統極雜，泛用免組態＝一套引擎通吃所有事業部，不必每個部門重做。
