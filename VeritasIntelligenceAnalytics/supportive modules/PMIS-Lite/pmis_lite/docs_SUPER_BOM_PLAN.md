# Super BOM 模板計畫 · 供電+散熱供應鏈
# 台達電 / 康舒 / 雙鴻 / 奇鋐 / 健策(建策) / 三集瑞 · 各事業部各產品

_在通用電子 BOM 之上，加「公司／事業部／產品家族」三維 + 散熱品類擴充，一套模板通吃供電與散熱兩域。引擎已實作測試（39/39）。_

---

## 一、為什麼要「Super BOM」

這六家是 **AI 伺服器的供電＋散熱供應鏈**：台達/康舒供電、雙鴻/奇鋐/健策供散熱，彼此又是上下游或競爭。它們的 BOM 有大量共通結構（多階、替代料、位號、合規），但橫跨兩個技術域（電源電路 vs 散熱結構）、且各有多事業部多產品。Super BOM 用**三維 + 雙域品類**把它們統一在一張模板下。

**安全界線（同前，也是賣點）：** 產品家族與品類骨架是**公開產業知識**；各公司實際 BOM／成本／供應商為**機密**，留各自本機主權 SSOT。**奇鋐與雙鴻是對手——實際 BOM 絕不共池，只共用公開骨架。**

## 二、三維結構（一套模板跨公司/事業部/產品）

Super BOM 表頭 = **三維 + 通用 BOM 36 欄 = 39 欄**。

| 維度 | 說明 |
|------|------|
| **Company** | 台達/康舒/雙鴻/奇鋐/健策/三集瑞 |
| **Business_Unit** | 各公司事業部（如奇鋐「液冷」、台達「電源及零組件」） |
| **Product_Family** | 產品家族（如「水冷板 cold plate」、「CRPS 伺服器電源」） |

**覆蓋：7 公司 · 23 事業部 · 66 產品家族**（公開登錄，見 `super_bom.py`）。

## 四、散熱品類擴充（補在電子品類骨架之上）

電子（通用）7 大類 + 散熱 3 大類 = **10 大類 / 38 子類**，跨域自動歸類：

| 散熱大類 | 子類 |
|---------|------|
| **散熱-氣冷** | 熱導管 Heat Pipe、均溫板 Vapor Chamber/3D VC、散熱片/鰭片、風扇 Fan |
| **散熱-液冷** | 水冷板 Cold Plate、微流道 MLCP、分歧管 Manifold、CDU、快接頭 QD、水冷頭 Water Block、水泵 Pump/RPU、冷卻液 Coolant |
| **散熱-界面/結構** | 均熱片 Heat Spreader/IHS、導熱 TIM、導線架 Leadframe、機殼 Chassis |

**實測歸類**：熱導管→氣冷/熱導管、水冷板→液冷/水冷板、快接頭→液冷/QD、均熱片→界面/均熱片、GaN→電子/電晶體、MLCC→電子/電容，全對。

## 五、驗證 + 樹操作（沿用通用 BOM，加三維檢查）

- `validate_super_bom`：通用 BOM 驗證（缺必填/位號≠用量/孤兒母件/單一源警示）**＋ 三維必填檢查**。實測抓出「缺 Commodity」與「缺維度」。
- `where_used` / `cost_rollup` / `diff_bom`：反查、成本累計、ECN 差異——通用可用。

---

## 六、與 AUTO SSOT 串接

```
各公司各事業部 BOM 匯入 → 三維標記(公司/事業部/產品家族)
  → 跨域品類自動歸類(電子+散熱) → 驗證(不遺漏+三維齊全)
  → 料號原封 + 系統自動編碼 → 版次/ECN append-only
  → 「為什麼改」從郵件/PLM 串進來 → 各自本機 SSOT
```
奇鋐與雙鴻各自的 SSOT **物理隔離**，只共用公開的產品家族與品類骨架。

---

## 七、導入順序（龍頭先拆 → 展開）

1. 以龍頭（散熱：奇鋐；供電：台達）最完整的產品家族拆標準骨架（公開）。
2. 同域次龍頭（雙鴻/健策/康舒）套同一骨架——散熱域彼此重疊高、供電域彼此重疊高。
3. 各公司實際 BOM 進各自本機主權 SSOT（機密隔離）。
4. 新產品家族/新品類 append-only 增量（如新一代 VR200 水冷板、MLCP）。

## 誠實提醒

1. **「建策」判定**：依散熱脈絡最可能是**健策 Jentech（3653，均熱片/導線架/MLCP）**；若你指**建準 Sunon（2421，風扇/RPU/水泵）**，模板兩者產品家族都已涵蓋。
2. **三集瑞-KY**：公開產品細節有限，登錄為「電子零組件/散熱結構件」，實際家族由資料填。
3. **產品家族為公開資訊**（各公司官網/公開報導）；各公司**實際 BOM 內容、成本、供應商為機密**，本工具設計上留各自本機、絕不共池或外傳。
4. 事業部/產品家族清單為便於分類的公開整理，非官方組織圖，客戶可自行增修（append-only）。
