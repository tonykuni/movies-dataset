## 2. 怎麼加總（公股買賣超定義）

```
公股買賣超(stock, day) = Σ_{b in 白名單} [ 分點_b 買金額 − 分點_b 賣金額 ]
```
- 逐檔逐日；買賣以**金額**（非張數）計，跨股可比。
- 正規化：`公股買賣超 ÷ 該股當日成交金額` → 得「公股占比」，再轉「對 N 日窗 z」（不寫死絕對門檻，R2）。
- **排除當沖**：先扣同分點當日買賣相抵部分（當沖假量，R1 精神）。
- **連續累積**（解你「單日抓不準」）：主訊號用 **5 日 / 20 日累積公股淨額**，非單日。

## 3. 怎麼跟集保大戶交叉驗證（confirmation，R4）

| 公股分點(日) | 集保千張大戶%(週) | 判定 |
|---|---|---|
| 連續淨買 | ↑（大戶增） | ✅ **真護盤/吸籌**（高信心）|
| 連續淨買 | ↓（大戶減） | ⚠ 可能是客戶單噪音，非護盤 |
| 淨賣 | ↓ | 出貨/退場方向 |
| 淨買 | 持平 | 中性，續觀察 |

- 規則：公股分點淨買**要 + 集保大戶%同向上升**，才升級為「護盤確認」旗標；否則只當「疑似」。
- 頻率對齊：分點日頻、集保週頻 → 用「週內公股累積淨買」對「該週大戶%變動」。

## 4. 護盤足跡的時序特徵（加權判別）

| 特徵 | 條件 | 權重 |
|---|---|---|
| 急殺日逆勢承接 | 大盤當日跌幅 > P90（對 N 日窗）**且** 公股淨買 z ≥ +2 | 高 |
| 權值股集中 | 公股買盤集中於台積電/鴻海/聯發科/官股金融 | 高 |
| 尾盤拉抬 | 13:00–13:30 公股買盤集中（需分時明細）| 中（資料難）|
| 成本線貼近 | 股價貼近公股分點還原成本（20/60/120/242/YTD）| 中 |

> 護盤旗標 = 「急殺日 + 公股淨買 + 權值集中」三者同成立（R4 確認，避免單一指標假訊號）。

## 6. 必記的 proxy 限制（為什麼不是真值）
1. **分點 ≠ 自營單**：分點是該券商**全客戶**委託總和，民間客戶單也走同分點。
2. **行庫自營不一定走自家券商**：可能分散到其他分點。
3. **T+1 更新**、部分券商不揭露、主力會**拆分點**規避。
4. 結論：只能推「疑似公股動向」，**不能宣稱=八大行庫自營部位**。引用一律加「據官股分點推估」。

## 8. 護欄（R1–R9 對映）
- **R1 Winsorize**：公股單日淨額夾 P1–P99，防爆量污染。
- **R2 零 hardcode**：用 z/percentile，不寫死「買超 X 億=護盤」。
- **R3 覆蓋率閘**：分點資料 T+1 未齊 → 當日不計分、標 stale。
- **R4 確認**：公股買 + 大戶↑ + 權值集中，≥2 同向才升護盤旗標。
- **R5 遲滯**：旗標連 2 日成立才翻轉，防抖動。
- **當沖剔除**：先扣同分點買賣相抵量。

## 9. 落地順序
1. 建**官股分點白名單 + 分點代碼對照**（對 TWSE 券商清單/第三方公股欄）。
2. 抓逐檔逐日分點 → 算公股買賣超（金額）→ ÷成交金額 → z。
3. 接 TDCC 週頻大戶% → 做交叉確認旗標。
4. 疊國安基金狀態（0/1）→ 輸出 D5 的 proxy 分數（進 data_quality_adjusted）。
5. 全程 raw audit、append-only；forward/proxy 一律 M，不進 verified。
