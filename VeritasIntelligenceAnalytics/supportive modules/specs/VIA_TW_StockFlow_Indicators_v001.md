## 0. 為什麼要超越三大法人
- 三大法人（外資/投信/自營）＝**分類法人**，看得到「法人整體」但看不到**「哪個主力、哪個大戶」**。
- 政府基金/主力/公司派的錢**不一定透過投信自營下單**（你先前的疑問）——要靠**券商分點**才抓得到。
- 方向性 = 不只看單日買賣超，要看**連續性、集中度、槓桿方向、避險方向**是否共振。

**方法論（解你「上次抓大戶不理想」）**
- 分點會**跨券商分散**（外資用多分點）、**隔日才更新**、**部分不揭露** → 單日抓不準。
- 改進：① 用**連續 N 日累積**分點淨額（非單日）；② 建**特定分點白名單**（外資/主力/地緣）；③ 與**集保大戶**交叉驗證（分點買 + 大戶%升 = 確認吸籌）；④ 排除**當沖分點**（買賣相抵的假量）。

## 8. 方向性判別（多指標共振評分）

**單指標不可信，看共振：**
| 訊號 | 吸籌/流入（偏多） | 出貨/流出（偏空） |
|---|---|---|
| 主力分點 | 特定分點連續淨買 | 連續淨賣 |
| 集保大戶 | 千張大戶%↑、散戶%↓ | 大戶%↓、散戶戶數↑ |
| 三大法人 | 連買、投信作帳 | 連賣、外資調節 |
| 融資 | 融資減、股價漲(良性) | 融資暴增、股價跌(散戶套牢) |
| 借券賣出 | 減少(空方回補) | 增加(法人放空) |
| 個股期貨 | 法人淨多增 | 淨空增 |

- **強訊號 = ≥3 層同向共振**（分點＋大戶＋法人）。
- 正規化：所有買賣超一律 **÷ 成交金額或市值**，跨股可比；再轉「對 N 日窗 z」。
- 排除雜訊：先扣**當沖、權證避險、ETF 被動**造成的假流向。

## 10. 缺口 / 待建
1. **分點資料**：TWSE 官方需自行彙整逐檔逐分點；實務多用第三方 API（需授權）。建白名單 + 連續累積邏輯。
2. **權證/CB 避險拆解**：隱性買賣盤，需自建推估模型。
3. **ETF 被動流扣除**：換股日/申贖造成的成分股假流向，需先建被動流模型再扣。
4. **政府基金/八大行庫**：仍無 API，靠分點特徵(特定官股券商分點)+揭露推估——這是你原始問題的核心，**用官股券商分點清單去逼近**。
