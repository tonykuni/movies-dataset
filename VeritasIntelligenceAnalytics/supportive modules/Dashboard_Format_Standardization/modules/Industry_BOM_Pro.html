08 分析方法論：從 Raw BOM 到 投資結論

def A · 拆 BOM

建立 L0/L1/L2/L3 層級，定義材料、零件、模組、系統、終端產品與替代料。

def B · 對成本

把單價、用量、良率、匯率、折舊、運費、關稅轉成同一成本基準。

def C · 看供需

追蹤產能、稼動率、交期、庫存週轉、客戶拉貨、供應商集中度。

def D · 連財務

轉成 ASP、COGS、毛利率、營業槓桿、EPS、Forward PER/PBR 情境。

def E · 驗證

用財報、法說、拆解報告、海關、通路報價、招標與新聞交叉驗證。

def F · 找 Alpha

尋找市場尚未定價的成本下降、缺料漲價、替代品滲透與毛利率拐點。

def G · 反論證

建立需求反轉、價格戰、技術替代、客戶砍單、法規限制與地緣風險。

def H · 回測

把 BOM 因子轉成訊號，回測報酬、波動、最大回撤、勝率與因子衰退。
