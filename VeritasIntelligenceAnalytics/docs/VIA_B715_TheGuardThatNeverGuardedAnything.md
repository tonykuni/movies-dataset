## 二、那 18 支:一台把假綠寫進報表的機器

舊導入器 `via_accel_injector_v0101` 判「這支已經有橋了」的條件長這樣:

```python
if MARK in text or "VIA_SuperAccel_Module" in text or "VeritasCeleritas" in text:
    return {"state": "SKIP", "note": "已橋"}
```

後面那兩個條件的意思是:**文中提到加速器的名字,就算有橋**。

於是任何一支在註解裡寫過「本引擎可搭配 VeritasCeleritas」的 `.py`,
從此永遠被報成「已橋」—— 實測**18 支**就是這樣躺了不知道多久。

更荒謬的是:那兩個條件**本來想保護的東西根本不需要保護**。
`VeritasCeleritas.py` 自己帶 2 個真標記,`VIA_SuperAccel_Module.py` 帶 1 個 ——
它們**早就有橋**,第一個條件 `MARK in text` 就攔下來了。

> **那道守衛從來沒有保護過任何東西。它唯一的作用,是把 18 支假綠寫進報表。**

`v0102` 拆掉那兩個條件,重跑:**注入 18 支**。
現在 2584 面 · 帶橋 2580(99.8%)· 缺 **0**。

剩下 4 支在批597 凍結夾裡(MANIFEST 封章指名自身 `.py`,注進去就毀章)——
**具名豁免,寫得出為什麼,不混進分母當綠**。
