## 三、兩條鏈的正典形狀

### VDF —— 扇出型(十道並行)

```
via-vdffetch [年份]
  → 年份旗標 → 25 加速器點亮 → Hydra 哨兵 H1–H6
  → 十一步資料鏈 / **十道並行**(MDL134 lanes)
  → 逐道:家族境 python · 逾時 kill · checkpoint · 讓庫律
  → 存證(逐道 rc 四態,任一道不擋其他道)
```

**為什麼是扇出**:VDF 的十道彼此**不相依**(價格 / 籌碼 / 營收 / ETF / 宏觀…),
唯一的共用資源是 DuckDB 單寫者鎖 —— 所以**並行 + 撞鎖序跑複判**是對的形狀。

### VRN —— 串接型(四站鏈 + 收尾閘)

```
via-vrnin(收件夾)
  → ENG072 首頁擷取 → ENG073/074 表格與財務 → ENG080 一題四點文摘
  → CGC_MDL141 收尾閘:逐份五段鏈核對 DONE | FAIL | PENDING
```

**為什麼是串接**:VRN 每一站**吃上一站的產出**,扇出沒有意義;
真正的風險是「上游沒料下游假裝有」——所以收尾閘要**逐份**核對,
而且 `PENDING`(還沒輪到)要跟 `FAIL`(真的壞)分開判。

## 四、最常重蹈的三個錯(台帳裡反覆出現)

1. **寫死版號** —— 163 筆裡一半在修這件事。任何路徑一律 `Get-VIANewest`。
2. **把缺料判成壞掉** —— `rc=1` 常常是「庫還沒回補」。缺料要能說出**缺哪一張表**。
3. **紅燈不指名紅在哪** —— 只印「RED 33/35」等於只講了一半(批582 才修掉)。

## 五、直接可用

```powershell
via-vdffetch 2023      # VDF 扇出:十道並行 + 哨兵 + 逾時不卡斷
via-lanes              # 十道並行安全編排(單看編排)
via-vrnin              # VRN 收件夾 → 四站鏈
via-closeout vrn       # 收尾閘:逐份 DONE / FAIL / PENDING
via-bus                # 匯流排:單一調度口
via-oneshot            # 36 段一次跑完(上面全部的合體)
```
