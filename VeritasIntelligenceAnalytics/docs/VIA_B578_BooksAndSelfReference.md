## 二、這一批被自我指涉咬了三次 —— 而且其中一次差點變成「假進步」

**① 開新版號就偽造改善(最危險)。**
`CGC_MDL164` 判「誰在讀這本冊」時寫的是「不把 `__file__` 算成讀者」。
我一開 `v0101`,**舊的 `v0100` 立刻變成每一本冊的第二讀者** ——

> 如果我沒回頭看那三本是誰讀的,就會寫一句「批578 把單一讀者補完了」。
> 那是**我自己的版本號造出來的假改善**,比假綠更難發現,因為它看起來像進步。

修法:排除**整個家族**(`stem.rsplit("_v",1)[0]`),不是那一支檔。修完回到 3 本(真實)。

**②** `CGC_MDL160` 的 owner 判定,把**閘自己 docstring 裡舉的頁名例子**
(我拿 `VIA_UI_Hub_v0108.html` 當例子)算成那張頁的 owner。

**③** 連「檢查原始碼裡沒有 `--apply`」這種檢查,**檢查句本身就把那個字寫進檔案**,
於是它永遠判自己有。改成用組字串。

三件事同一條律(`LL133`):

## 三、`SUP_MDL750.adopt()` —— 既有頁一行接上 Veritas 表頭

```python
html = adopt(html, "VeritasDataForge")      # 產頁引擎寫檔前加這一行就好
```

三件事守死:

1. **冪等** —— 接過的頁(帶標記)原樣回傳,再生一百次也只有一個表頭
2. **不覆蓋既有版面** —— 只注入表頭自己的 CSS 與令牌,**刻意不碰 `body` / `html` / `*`**
   (接表頭不該順便換掉人家的底色與字體,那不是統一,那是覆蓋)
