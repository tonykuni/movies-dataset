## 五 · 我犯的三個錯,三個都被自己的閘擋下來

### ① 區間重疊 —— AST 定位切了兩次

第一版的 `purge_py` 把「整鍵的 span」和「它值裡那幾個字串的 span」放在同一個清單,
去重時只跟**前一段**比包含關係。合成檔當場被切出語法錯。
**改完重新解析那一關擋住了**(fail-closed,一個字都沒寫下去)。
改成由小到大做真正的區間聯集,再由後往前切。

### ② 台帳被自己的第二跑刪掉

第二次 `--apply` 跑第二輪時,`apply()` 從頭造了一份新台帳 ——
**第一輪那八檔的原文當場從台帳上消失**(檔案已改,原文只剩 git 裡有)。
刪是操作員的裁定,可以;但**刪的留痕自己被刪掉**就不行了,那正是「沒有留痕的刪」本身。
已自 `git HEAD` 原樣補回 21 檔,並改成 `_merge_ledger`:同一個 path 永遠保留**最早**那一份 `original`。
→ **這件事寫進台帳的 `note_b679`,不是補好就算沒發生過。**

### ③ 升版註記插進了 docstring 前面

`_inject` 把批679 的說明放在 `# -*- coding -*-` 與 `r"""` 之間,
首頁全能引擎的 ㉔ 逐字釘著 `src.startswith('# -*- coding: utf-8 -*-\nr"""')` —— 當場紅。
改成用 **AST 取 docstring 的 `end_lineno`**,把註記放在 docstring **之後**;不是數行數。
