## 三 · 去重怎麼守

操作員說「彙總去重」。去重的做法**不是事後比對,是事前只給一條路**:

```python
FACE_SOURCES = (
    ("實測經過哪些引擎步驟 · VRN", "VIA_Reports/vrn_chain/VRNCHAIN_latest.json", ...),
    ("引擎狀況 · 六域",           "VIA_Reports/state_matrix/STATE_latest.json", ...),
    ...
)
```

每一面在這張表上登記自己的**一個出處**,頁上抬頭把出處印出來;
兩面搶同一個檔 → 自測第⑭檢當場敗。

> 同一個數字從兩條路進來,哪天兩條路不一致,頁上會同時出現兩個答案——
> **而看的人不會知道該信哪一個。**

## 五 · 一個當場踩到的坑

第⑮檢我第一版寫「源碼裡不准出現 `subprocess.run`」,想守「零重算」。
當場敗——因為 `_git()` 就在用它**讀**分支與 HEAD。

**讀狀態不是重算。** 把讀也禁掉,那一檢就只是在禁一個字,不是在守一件事。
改成問兩件真的:① 有沒有開庫/寫庫 ② 每一個 `subprocess` 是不是都只拿去跑 `git`(走 AST)。
