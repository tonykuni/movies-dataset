## 第一版我報錯了維度

> 正典名冊 1,980 檔,價表只涵蓋 892 檔 → **缺 1,088 檔**

這句話**讀起來像一條零散的長尾**,補法也像「慢慢補」。

照 `market` 拆開之後,真相塌成一句話:

| market | 冊 | 價表有料 | 價表缺料 |
|---|--:|--:|--:|
| TPEX 上櫃 | 892 | **892(100.0%)** | 0 |
| TWSE 上市 | 1,088 | **0(0.0%)** | **1,088(100.0%)** |

**整個上市市場一檔都沒有。上櫃是 100% 齊的。**

佐證乾淨到不可能是巧合:

- 價表 892 個 ticker,後綴**全部是 `.TWO`**
- `tw_listings` 892 列,`market` **全部是 `TPEX`**
- 而 `VDF_ENG054` 的註解寫的是「**雙所**+ETF」

VRN 那 37 檔個股裡有價的 5 檔 —— 4171 瑞基、3675 德微、4153 鈺緯、6147 頎邦、6143 振曜 ——
**全部是上櫃**。2330 / 2317 / 2454 / 3008 / 1101 一檔都沒有,因為它們全是上市。

> **「補 1,088 檔」沒人知道怎麼開始;「把上市那一所抓回來」是一件事。**
> 差別只在有沒有照 market 拆。→ **LL273**

## 順手照出的第二件:有名字,沒有值

`VDF_ENG064_HistoryBackfill` 的計畫裡寫著:

```python
'universe_scope': '既有 tw_daily_prices 票;未曾入庫新票另列 UNIVERSE_RECONCILIATION'
```

**全樹搜過 —— `UNIVERSE_RECONCILIATION` 只出現在那一個註記字串裡。**
沒有人產出它、沒有人讀它、沒有一道檢量它。缺口被講出來了,然後就放著。

更糟的是同一支的取票:

```python
tickers = _tickers_tw(con)   # SELECT DISTINCT ticker FROM tw_daily_prices
```

**它永遠加不進新票**,是個閉環:有的才補,沒有的永遠沒有。
而那個閉環的出口,名字就寫在它自己的註記裡。→ **LL274**

## 做了什麼

`VDF_ENG090_DataCoverageGate v0104` + `roster` 車道(23 檢),把那張表真的做出來:

```
via-vdfcov roster
```

```

  [TWSE    ] 冊  1088 · 有料     0(  0.0%) · 缺  1088   ← **整所缺席**
```

紀律:

- **零網路、零寫、唯讀**開庫
- **不假造**:名冊缺席 / duckdb 缺 / 庫缺 → 一律 `ABSENT` 並指名因由,絕不自己編一份票號清單頂替(L30 一個出處:名冊正本只有 `CGC_MDL142`)
- `market_rollup` 抽成**純函式**才驗得了(LL262),檢㉒ 驗「判得出整所缺席」、檢㉓ 驗「全有料時不得誤報」
- **零註冊面**:`via-vdfcov` 早就在冊上且解析尾版,新動詞騎既有短令,不新開命令、不加梭
