### 而且我第一版量錯了,錯得很大

用 `talib` 當關鍵字全樹掃 → **「活件曝險 578 處」**。如果就這樣回報,你會以為系統爛掉了。

拆開來看,那 578 處是:

- **版本史** —— `CGC_MDL064_SelftestGrid` 180 個歷史版號、`CGC_MDL095_DeckServer` 11 個,各算一次

換成正確的尺 —— **只看尾版 × 只比 `import talib` / `from talib import` 語句**:

```

真的 import 的       **0 支**
只是提到的           40 支(逐支看過,全是執法程式)
```

**578 → 0。**
