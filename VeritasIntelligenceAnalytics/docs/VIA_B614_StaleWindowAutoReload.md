你打了三句,得到兩種不同的回答,而兩種都講對了:

```
via-presync   → [VIA] 冊上有,但本視窗沒點到。本視窗點的 v0220,磁碟最新 v0222
via-allinone  → [VIA] 冊上有,但本視窗沒點到。本視窗點的 v0220,磁碟最新 v0222
```

第三句是對的:`via-regen` 在 **v0223**,而 v0223 在你還沒拉的 commit 裡。

**而要拉新冊得先用 `via-presync` —— 那正好是點不到的那一支。** L85 第四次。

## 一個短令要能被打到,三件事缺一不可

1. 那個 commit 他拉下來了
2. 檔在磁碟上
3. **他這個視窗點源過那一版冊**

我一直只顧到 ①②。第 ③ 件我從來沒在交付前問過自己。
新法 **L89**:解卡用的、第一次用的、跨版本的,**一律給完整路徑或零依賴貼上區塊,不給短令**。
短令是穩態工具,不是解卡工具。

## 批571 做對了一半

批571 我做了一件對的事:短令找不到時,冊自己分辨是哪一種,並印出版本對照。
這個診斷這一次**精準命中**。

可是它只講,不做 —— 你拿到一段正確的診斷,然後還是得自己再打一次;
而這一次要打的那一句正好也點不到。**診斷再準也出不去。**

v0224 把它從「講」變成「做」:

```
[VIA] 'via-regen' 本視窗點的是 v0220,磁碟最新是 v0224 → **自動重點源後重跑一次**
...
=== 再生物還原閘 v0100 ===
[倉] /home/user/movies-dataset
[計] 髒的追蹤檔 0 · 再生物 0 · 刻意入倉 0 · **不明 0**
[裁決] rc=0 (GREEN)
```

容器 pwsh 7.4.6 端到端實跑過:假裝本視窗點的是 v0220、且 `via-regen` 不在 session 裡,
打 `via-regen` → 自動重點源 → 引擎真的跑完。

防迴圈:同一個名字只自動接一次(`$global:VIA_AUTORELOAD` 記名),
接第二次還不通才退回印建議。

### 先踩到的陷阱

`$VIA` 原本只活在「點源它的那個 scope」。如果在 scriptblock 裡點源,
離開那個 block 就沒了 —— 之後從全域呼叫**任何**短令都會找不到根。

所以同時釘一份 `$global:VIA`(`$VIAGrokVerbs` 同理)。
`function global:` 的函式解析 `$VIA` 會沿 scope 鏈走到 global,就接得上。
原本那一行一字未動,只增不減。

## 這一版救不了你「現在這個視窗」

老實說:你現在的視窗裡跑的是 **v0220 的 handler**,它還是只會給建議。
自動重點源要等你下次開新視窗(或手動重點一次)才生效。

所以這一次仍然要用**路徑**,不用短令 —— 這正是 L89 說的事。
