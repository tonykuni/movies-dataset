## 語意層 vs 語法層

ENG085 的類別是**語意**(標題 / 表 / 本文 / 其他);
`block_type` 是**語法**(heading / table / paragraph / ordered_list…)。

一個語意可以對到多個語法。我第一版把「本文」只對到 `paragraph`,於是 138 塊全報成對不上
—— **那是假紅,而假紅跟假綠一樣傷**(LL260)。
