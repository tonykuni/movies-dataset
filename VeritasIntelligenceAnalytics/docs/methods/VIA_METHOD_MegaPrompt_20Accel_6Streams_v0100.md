## 一、原件(逐字保存)

請啟動「全自動沙盒測試修正治理系統(Autonomous Sandbox Governance & Repair Engine)」,
啟用全部 20 個加速器,對所有子系統(VRN / VDF / VAP / 其他相關模組)執行三輪全景式分析、
自動修復、自動部署、自動整合與穩定化流程。

### 【核心原則與執行指令】

全景式分析後,識別所有問題及錯誤,透過 AST 彈性或精準定位;在「不傷害系統、
不造成九頭龍連鎖風險(Zero-Hydra Risk)」的前提下,可同步修正的問題即刻同步修正,
不可同步的問題嚴格按依賴順序修正;在後續流程中,拆分為「六個獨立流程」在零九頭龍風險前提下同步推進。

### 一、核心執行環境與架構整合要求

1. **全函式庫註冊與引擎整合**:自動掃描並註冊所有依賴函式庫,擴充缺失功能,統一整合成高效能 Python Engine。
2. **非阻塞啟動器**:生成專用 PowerShell 啟動腳本(launch.ps1),確保執行過程「不關閉、不阻塞、不卡斷」,背景非同步派工。
3. **自動化環境與路徑配置**:自動初始化目錄結構、環境變數與模組路徑,一鍵部署所有核心與支援模組。
4. **自動跳出 HTML UI Matrix 報告**:
   - 採用 **略小字體(small font)** 呈現高資訊密度。
   - 表格高度與寬度具備 **自適應最佳化佈局(Auto-Optimized Layout)**。
   - 表格內部文字過長時強制 **自動換行(Auto-Wrap)**,上下整合不溢出。
   - 清楚劃分四大標準分區:`MODULE` / `ENGINE` / `FUNCTION-LIB` / `OTHERS`。
5. **即時反饋機制**:內建動態進度條(Dynamic Progress Bar)與動態情境說明(Dynamic Status Narration)。

### 二、三輪全景式分析(每輪循環必做)

- **Panoramic Analysis**:全系統代碼、配置與架構無死角掃描。
- **Error Identification**:語法、語意、類型與執行期潛在異常標記。
- **AST Elastic / Precision Locating**:依問題層級動態切換 AST 語意彈性比對或語法樹精準定界。
- **Optimization Points**:複雜度、瓶頸與冗餘路徑識別。
- **SSOT Alignment**:驗證跨模組數據與配置一致性。
- **Hydra Risk Detection**:鎖定高耦合、修改易引發連鎖崩潰之脆弱節點。
- **問題分流分類**:`Parallel-Fixable` / `Sequence-Dependent`。
- **Multi-Subsystem Synchronization**:跨 VRN / VDF / VAP 模組即時狀態同步。
- **動態輸出 HTML UI Matrix**:即時更新紅黃綠燈(RYG)健康指標、進度條與狀態日誌。

### 三、六個獨立同步推進流程

1. **Stream 1**:代碼層與 AST 重構流程
2. **Stream 2**:SSOT 資料與配置對齊流程
3. **Stream 3**:子系統依賴解耦流程(VRN / VDF / VAP)
4. **Stream 4**:性能瓶頸與死碼清理流程
5. **Stream 5**:沙盒回歸驗證與測試流程
6. **Stream 6**:UI Matrix 渲染與非阻塞部署監控流程

### 四、三輪精準修正策略(嚴格限制最多三輪)

- **第 1 輪 全面性修正**:同步修正所有 `Parallel-Fixable`;嚴格隔離高 Hydra 節點。
- **第 2 輪 順序性修正**:依依賴拓撲排序推進;每步沙盒驗證;高風險節點僅輸出建議,不強制套用。
- **第 3 輪 收尾與硬化**:微調、格式化、死碼清理、性能極致優化。

### 五、沙盒驗證與持續穩定循環

```text
test → debug → upgrade → test → debug → optimize → test → debug → consolidate → test → debug → user-test → debug
activate system → test → debug → until perfect
```
