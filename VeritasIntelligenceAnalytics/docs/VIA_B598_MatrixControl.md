# 批598 — 中央管理系統的矩陣控制台 `via-vcgc matrix`

操作員令:「在中央管理系統設一個管理啟動各子系統及引擎及設定參數的指令,
透過他們啟動或單獨啟動,測試矩陣化管理;AI 啟動他們看結果,錯誤顯示於一頁 HTML,
一頁式自小多矩陣自動調節欄寬列高最佳化;引擎檢查邏輯單獨測試;
**已經內建指令全景式修復工具,引擎請用他節省 TOKEN**;註冊實測。」

---

## 一、先量,再決定要不要造

「引擎請用他」這句是關鍵。所以第一步不是寫程式,是**量樹上已經有什麼**:

| 要的能力 | 樹上已有 | 動詞 |
|---|---|---|
| 子系統/引擎/參數冊 | `CGC_MDL148 EngineBus` | `catalog` |
| 啟動 / 單獨啟動 | `CGC_MDL148 EngineBus` | `matrix --ids` / `call --item` |
| 引擎檢查邏輯(誠實四態) | `CGC_MDL158 全景稽核修復` | `run_tests` / `judge` |
| 全景修復候選 | `CGC_MDL158 全景稽核修復` | `scan` / `fix --apply` |
| 頁頭 / 主題令牌 / 頁腳 | `SUP_MDL750 Veritas 正典頁頭件` | `page()` |

**一行跑法都不必新寫。** 缺的只有一件:**沒有一個中央指令把它們串成一頁**。

順帶更正一個數字:`CGC_MDL148` 的文件寫調度冊「37 項」,**實際冊上是 63 項**——文件比冊舊。

## 二、新動詞(零 `.ps1` 改動)

`via-vcgc` 本來就把 args 全轉給**尾版** MDL149,所以加一個動詞就等於加一個短令 —— **L70 完全不必碰 `.ps1`**。

```
via-vcgc matrix                        全景 → 一頁 HTML
via-vcgc matrix --family vdf           只看一個子系統
via-vcgc matrix --ids tw_align,tw_need **單獨啟動**點名的項(寫庫動詞只認這條路)
via-vcgc matrix --engine CGC_MDL156    **單獨測**一支引擎的檢查邏輯
via-vcgc matrix --apply                真跑(預設 PLAN)
via-vcgc matrix --no-tests             不測引擎(那一格標成「沒量」,不冒充綠)
via-vcgc matrix --full / --json
```

rc:**0 綠 · 1 紅 · 2 黃**(有修復候選/缺件/沒量 —— **黃不是綠**)。

預設 **PLAN**:一個開關按下去發動幾十支回補,那不叫方便,那叫地雷。

## 三、一頁四矩陣

`VIA_Reports/vcgc/VIA_UI_MatrixControl_v0100.html`

1. **子系統 × 引擎 × 參數冊** — 在位 ≠ 跑得動,這張只說在不在
2. **啟動矩陣** — `--ids` 單獨啟動
3. **引擎檢查邏輯** — 誠實四態,`--engine` 單獨測一支
4. **全景修復候選** — **只列不修**(要修走 `via-panorama fix --apply`,那是另一個明點)

**自動調節欄寬**是真的量出來的,不是寫死的:逐欄量**每一格的顯示寬度**
(CJK 算 2 格)取最大值,夾在 `[6ch, 44ch]`。夾上限是因為一格塞 200 字
會把其他欄擠成一條線——**最佳化不是讓某一欄贏,是讓整頁讀得動**。
第㉒檢用合成語料真跑證明:**窄 6 < 寬 32 < 上限,超長夾成 44**。

卡片用 `repeat(auto-fit, minmax(min(100%,30rem),1fr))`,手機自動收成一欄;
列高由 `--mx-row` 令牌控,單行省略、滑過展開,**零 JS 外連**。
**壞的排前面**,紅列底色標出來 —— 錯誤要看得到,不是埋在第 80 列。

頁頭/令牌/頁腳走 `SUP_MDL750` 正本,所以 **U/I 統一閘 22/22 照樣綠**。

## 四、不准自己重寫跑法(第㉑檢)

新動詞最大的風險是**又造一支平行匯流排**。所以判準寫成可執行的檢:

> `matrix_run` 的原始碼裡必須看得到 `bus.catalog(` · `bus.matrix(` ·
> `rep.run_tests(` · `rep.scan(` 這四個正典呼叫,**缺一個就 FAIL**。

缺一個,就代表那一段自己寫了跑法。
