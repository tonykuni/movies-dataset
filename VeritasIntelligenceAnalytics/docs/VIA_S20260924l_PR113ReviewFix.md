## 一 · 一句話

第十一段把 ENG079 的 `scan` 改成真的唯讀(不再先加欄),可是計畫那條 SQL 還拿表上**還沒有的欄**去比,新來源多一欄時計畫就 Binder 錯。
修在正典:只數不寫時,表還沒有的欄當 NULL 數——跟 `--apply` 先加欄、舊列那一欄是 NULL 之後實寫看到的一樣。
