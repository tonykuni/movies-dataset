## 四 · 啟動 VRN 的 PowerShell(交付②)

`Invoke-VIA-VRN-v0100.ps1` / 短令 `via-vrnrun`。五步照順序——**順序就是它存在的理由**:

```
V1 via-vrnbook build          冊即鏈(冊釘舊版號就會敲到你剛修好那支的前一版)
V2 via-vrnchain run           六層 44 節點
V3 via-repairprice --apply    庫價與上漲空間重算(零網路)
V4 via-vrnmatrix              判對率 + 可判率,兩個都印
V5 via-console                標準 HTML U/I
```

開頭先印**本窗對著哪一棵樹、點的是哪一本冊**——因為工作站剛剛實錄過一次:
