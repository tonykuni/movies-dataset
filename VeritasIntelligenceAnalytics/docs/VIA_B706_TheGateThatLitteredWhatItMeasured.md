## 二、最重的一條:我的煙測在倉裡留下十七個垃圾檔

v0101 用 `cwd=p.parent` 跑探針 —— **被測件自己的資料夾**。
而有幾支在 import 期拿 `C:\Users\tonyk\Downloads\...` 當**相對路徑**開檔。
在 Linux 上那不是錯誤,`open()` 會照著建:

```
supportive modules/network/C:\\Users\\tonyk\\Downloads\\...\\vdf_akshare_sample_call_gate_result_v0272.json
supportive modules/audit_tools/C:\\Users\\tonyk\\Downloads\\...\\vdf_fred_small_scope_final_validator_result_v0252.json
…共 17 個,檔名裡全是反斜線
```

**量的動作改變了被量的東西**(LL368)。而閘的副作用偵測只盯 `VIA_Reports`:

```python
before = sorted(str(x) for x in live.rglob("*"))   # live = VIA_Reports
```

所以它**完全沒看見自己造的那十七個**。它有一條「唯讀律」的檢,而那條檢只看一個夾。

### 修法:沙箱 cwd + 溢出偵測

探針改在 `TemporaryDirectory` 裡跑。相對路徑寫入落進拋棄式暫存夾,
跑完暫存夾非空就照實報 AMBER。實測驗過:**倉內變動檔數 1 → 1**。

修完的數字才是真的:

| 態 | v0101(老尺) | v0102(零足跡) |
|---|---|---|
| SMOKE | 108 | 89 |
| **AMBER** | **0** | **17** |
| EXTPATH | —(全算 RED) | 5 |
| SCRIPT | —(全算 RED) | 3 |
| NEEDLIB | —(全算 RED) | 2 |
| **RED** | **6** | **0** |

**AMBER 從 0 變 17 不是變壞** —— 那 17 支一直都在 import 期寫檔,
只是以前那些寫入直接落進倉裡而沒人量得到。

## 四、順手修掉的三件(都是被既有的檢抓到的)

1. **理由被截斷**(L62)。v0101 寫 `str(exc)` 切一刀,而且只報最外層。
   實測同一支在不同 cwd 下最外層例外不同(`FileNotFoundError` vs `ModuleNotFoundError: sklearn`)
   ——只報最外層又切一半,等於**把人指到錯的地方去修**。改成整句不截 + 例外鏈逐層。
2. **`--selftest` 判準兩個出處**。批705 把 AST 判準寫在格子裡,而 MDL147 裡另有一份字面判準。
   批706 收進 MDL147(它是煙測閘,「誰有真自測」本來就是它的判斷),格子改成**委派**,
   問不到才退回本地副本**而且要講**(L30 · 批698「委派不是複製」)。
3. **我引進了 `shutil.rmtree`**,被本檔既有的檢 ⑫「零搬移碼」當場抓到。
   那條檢是對的:一支宣告「不搬檔」的儀器不該有刪除呼叫,即使刪的只是自己剛建的暫存夾。
   改用 `TemporaryDirectory` 的 context manager 收尾,**紀律不必破例**。

## 五、同一族連中三次:字面禁用檢吃到了註解

| 次 | 症狀 |
|---|---|
| 1 | 檢 ⑲ 的**說明文字裡**寫著它要找的那個切片字面 → 自己判自己紅 |
| 2 | 針改成執行期組出來之後,**探針的註解**裡還留著那個字面 → 還是紅 |
| 3 | 檢 ⑫ 的 `shutil` 出現在「**我把它移除了**」這句註解裡 → 紅 |

三次都是同一件事:**記述一段被移除的舊寫法是文件該做的事**,
不該因此被判成「它還在」。否則下場只有兩個:檢一直紅,或為了讓檢綠而把文件寫糊。
治本:字面禁用檢一律先把註解行剝掉,只看**會執行的碼**。

## 五之二、全格子平行跑才照得出來的第二盞假黃燈

零足跡改完之後掛上格子,第一輪**第 316 站紅**:合成的乾淨件被判 `AMBER`,
而同一支單跑五次都是 `SMOKE`。

根因是 v0101 的寫檔偵測本身:

```python
before = sorted(str(x) for x in live.rglob("*"))   # 跑之前掃一次 VIA_Reports
...                                                 # 載入被測件
after  = sorted(str(x) for x in live.rglob("*"))   # 跑完再掃一次
res["wrote"] = [x for x in after if x not in before]
```

全格子是**平行**跑的 —— 別的站正在寫同一個 `VIA_Reports`,差集就被算到被測件頭上。
**共用資料夾的前後比對,量到的是整台機器,不是這一支。**

改成讓探針用 `sys.addaudithook` 記**自己這個行程**的 `open`。過程中又自己踩兩個坑:

| 坑 | 記到什麼 | 為什麼不算 |
|---|---|---|
| 1 | `__pycache__/*.pyc` | **直譯器自己**寫的位元碼快取,不是被測件的行為 |
| 2 | `'3'` | `os.fdopen` 也觸發 `open` 事件,那時參數是**檔案描述子編號**不是路徑 |

兩個都濾掉之後,兩個控制都成立:

* **負控**:400 個並行寫入 `VIA_Reports` + 乾淨件 → `SMOKE`(不再被並行騙)
* **正控**:import 期寫檔的件 → `AMBER`,而且印出實際路徑 `import_side_effect.txt`

## 八、新律

**LL383 儀器跑別人的碼,一律在拋棄式沙箱裡跑。**
用被測件自己的資料夾當 cwd,等於把它 import 期的每一次相對路徑寫入
都導進倉庫。**而且副作用偵測只盯一個夾的話,它連自己造的都看不見。**
沙箱不只是防污染,它還讓「這支會寫檔」這件事第一次變得**量得到**
——本批 AMBER 0 → 17 全部來自這一條。

**LL384 字面禁用檢要先剝掉註解。**
「這個字不准出現」的檢,如果連註解一起看,那麼**記述一段被移除的舊寫法**
就會被判成「它還在」。同一批裡連中三次。要嘛檢一直紅,要嘛把文件寫糊——
兩個都不對。禁用檢只看會執行的碼。

**LL386 副作用要歸屬到行程,不能靠掃共用資料夾的前後差。**
「跑之前掃一次、跑完再掃一次」在**並行**下是錯的判準:別人同時寫進同一個夾,
差集就被算到被測件頭上。本批實例:合成的乾淨件在全格子裡被判 AMBER,單跑五次都是 SMOKE。
要歸屬就用行程層級的機制(`sys.addaudithook`),並且記得濾掉**直譯器自己**的寫入
(`__pycache__/*.pyc`)與**非路徑參數**(`os.fdopen` 的檔案描述子編號)。

**LL385 判得出是腳本,就不要執行它。**
模組頂層讀 `sys.argv` 是「它是腳本不是模組」的硬證據,AST 就看得出來。
在跑之前判掉,比跑完再收拾便宜,也比跑完才發現它把整份工作做完了安全。
