## 但那 39 筆裡有幾個數字要先講

```
6873 泓德能源  目標 208 × 0.9630 = 200.31 ÷ 最新adj 68.0   → +194.6%   (報告 2025-08-19，13 個月前)
6768 志強-KY   目標 145 × 0.9401 = 136.31 ÷ 最新adj 61.7   → +120.9%   (報告 2025-12-04)
3014TT         目標 187 × 0.8427 = 157.58 ÷ 最新adj 130.5  → +20.8%    (報告 2023-10-05，35 個月前)
```

`+194.6%` **不是算錯**。股價真的從約 200 跌到 68,算法問的是「從現在看還有多少空間」,它就該是這個數。

問題是 —— **它在回答一個沒人問的問題。**

一份 13 個月前的報告,券商的目標價從沒更新過,股價腰斬再腰斬。把「+194.6%」寫出來,讀的人會以為那是一個現在有效的判斷。而**下游 ENG080 會把它寫進四點文摘**。

## 這不是個案,是這一欄的常態

容器 34 筆有目標價的報告:

| 報告距今 | 筆 | |
|---|--:|--:|
| ≤90 天 | 3 | 9% |
| 91–180 天 | 9 | 26% |
| 181–365 天 | 16 | 47% |
| 1–2 年 | 4 | 12% |
| >2 年 | 2 | 6% |

**91% 超過 90 天,65% 超過半年。**

## 治法兩半,第二半不歸我

**① 把年齡量出來、標出來**（ENG073 v0134）

```
6147  … → +20.8%  [124 天/AGING_180]
6143  … → +65.7%  [296 天/STALE_365]
```

兩個新欄 `report_age_days` / `target_freshness`。**`upside_adj` 的值一個字都沒動**(只增不減)。年齡是獨立的事實 —— 連「算不出上漲空間」的也要量,因為算不出的原因可能正是報告太舊。

**② 「多久算目標價失效」不歸我決定**

門檻擺成一行給你改:

```python
TARGET_FRESH_BANDS = ((90, "FRESH_90"), (180, "AGING_180"), (365, "STALE_365"))
TARGET_EXPIRED = "EXPIRED_OVER_1Y"
```

而且 **判燈完全不受年齡影響** —— `_v_upside` 對 `EXPIRED_OVER_1Y` 照樣給綠。矩陣只多印一行事實:

```
[目標價年齡] 算得出上漲空間的 2 筆：AGING_180 1 · STALE_365 1
  —— 舊報告的目標價從沒更新過，這個百分比在回答「從現在看」，不是券商當時的看法
```

要不要把過期的從綠燈拿掉、門檻改幾天,**是你的裁定**(LL90 同族)。
