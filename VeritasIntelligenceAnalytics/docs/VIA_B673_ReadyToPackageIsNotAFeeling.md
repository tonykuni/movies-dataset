# 批673 · 「準備打包」不是一句感覺

操作員令:
① 「受測字測字完成,邊修邊改,**三個專案到準備打包的程度**」
② 「A POWERSHELL TO LAUNCH AUTO DEPLOY INSTALLATION **BASED ON OUR THE LAST STATUS**.
   THEN USER USE THE SYSTEM ON HTML U/I」

## 一 · 先拒絕一個數字

「準備打包的程度」最容易交出去的答案是一個百分比:**完成度 87%**。
那種數字誰都推不翻,也就誰都不用負責。

所以 `CGC_MDL174_PackagingGate` 不給百分比。它給**每個專案七列**,
每一列一個誠實態,每一列後面掛一個**下一步**(L92):

| 列 | 量什麼 | 為什麼是這一條 |
|---|---|---|
| ① 引擎在位 | 冊上點名的尾版,樹上找不找得到 | 冊樹不同步 = ABSENT,不是「快好了」 |
| ② 自測門覆蓋 | 帶 `--selftest` 的比例 | **這是誠實分母**(批671 LL317) |
| ③ 自測綠 | 從最新格子存證取該家族的站 | **存證比樹舊就記 NODATA**(批669 律) |
| ④ 四面登錄 | LL199 四面 + **L101 短令重名** | 少一面就打不開,重名會默默蓋掉 |
| ⑤ 家族境可跑 | RunGate 存證 | 容器量不到家族境 = GATED,不是壞掉 |
| ⑥ 落頁同一份規格 | 跑完落報告頁的支有沒有接 MDL173 | 規格散了就不是規格(批672 LL321) |
| ⑦ 資料證據 | 該家族正典表的實際列數 | **空庫 = NODATA 不是 RED** |

判準是:**GREEN 才算就緒**。
NODATA / GATED 不是壞掉,但把「量不到」講成「好了」就是假綠——
批671 那天同一把尺同時造出假紅跟假綠,不想再來一次。

**本閘零動作**:不裝套件、不設同意閘、不改任何檔。自測第⑫檢就在咬這一條
(源碼裡不准出現 `pip install` / `Remove-Item` / 設同意閘的賦值)。

## 二 · 閘第一跑就照出三件真的

### ① 兩支梭從來沒被做出來

`bin/via-state.cmd`、`bin/via-vrnbook.cmd` 不存在。
根目錄那一面有,bin 那一面沒有——批622 與批664 各漏了一次。
補上之後 ④ 從 `梭(根+bin) 1/2` 變成 `2/2`。

### ② 三個短令重名(L101)

| 短令 | 先定義 | 後定義(會贏) | 被蓋掉的那一支還有門嗎 |
|---|---|---|---|
| `via-ssot` | 172 行 · MDL115 全樹 regex 清冊 | 1077 行 · MDL155 | 有:`via-ssotregex` |
| `via-ui` | 379 行 · MDL130 UIBridge | 828 行 · MDL160 正典 TEMPLATE | 有:`via-uibridge` |
| `via-panorama` | 614 行 · launchers 啟動器 | 1270 行 · MDL158 | 有:`via-panorama-run` |

PowerShell 後定義覆蓋前定義,**而且不報錯**。
被蓋掉的那一扇從此打不開,症狀只會是「怎麼沒反應」——
**這種壞法沒有紅燈,所以要有人去數。**

三行死定義換成墓碑註記(寫清楚那支引擎的門在哪裡,免得有人再加回來)。
刪掉的是一扇**本來就打不開**的門,行為零變更。

### ③ 我自己的尺量錯了一次

⑥ 第一版寫「原始碼裡寫得出 `.html` 就算落頁」,於是 VIA 的 97 支裡有 80 支被判
「自己帶一份 CSS」——那裡面有 U/I 產生器、收容件、批647 的位元正本頁。

操作員那句話是**「以後跑完都要生成矩陣式報告」**,講的是**跑完落在 VIA_Reports
的那種報告頁**,不是所有 HTML。範圍收窄之後:VIA 36 支(28 支還沒接)、
VDF 2 支、VRN 4 支(3 支還沒接)——這才是一張做得完的清單。

> **拿一個沒人約定過的判準去量,量出來的紅燈是我發明的。**(先疑尺不疑樹 L93)

## 三 · 依現況佈署:兩條車道永遠分得開

`CGC_MDL175_AutoDeploy` 只做一件事:**照上一次量到的現況,排出一條走到 HTML U/I 的路**。
它自己不跑任何一步(自測第⑧檢咬這一條)。

```
auto  零風險可代跑:同步冊 · 重建索引 · 再生頁 · 跑四條鏈 · 全格子 · 打包閘 · 開 U/I
hand  **操作員的手**:裝套件 · 開同意閘
```

hand 這兩件 AI 永不代做。**不是做不到,是不該做**:
裝套件會動到你的環境,開同意閘等於替你決定要不要觸網。
所以 hand 那一欄給的是**可以直接貼的一行**,貼不貼是你的事。
缺套件那一行還會把該家族境的 python 具名寫進去,
不會給你一句「請安裝相依套件」這種貼不動的話(L97:要人手打路徑就一定會打錯)。

**「LAST STATUS」全部讀既有存證,不重新量**:打包閘 / 全格子 / 六域現況 / 家族境。
存證比樹舊就**不拿來判**,改排一步「先去量」——那份講的是另一棵樹(批669 律)。
存證缺席也不是壞掉,一樣排一步「先去量」,**不假裝知道**。

### 一道門閂

`via-deploy -Apply` 在跑每一句之前,再比對一次白名單:
只准 `via-*` 單句、零殼元字元(`; | & \` $( > <`)。

> 計畫是資料,**資料不該有本事在操作員的視窗裡長出分號跟管線**。

不在白名單的步一律降成 hand(印出來讓人貼),不會硬跑。
自測第⑮檢是負向的:把 `$env:VIA_NET_CONSENT='YES'` 硬塞進 auto 車道,它必須被擋成 hand。
