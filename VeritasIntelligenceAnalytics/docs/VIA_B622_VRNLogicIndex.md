# 批622:VRN 邏輯整合 —— 指過去,不複製

操作員令:**「想把今天的 VRN 邏輯整合一遍,不要遺漏」**。

---

## 一 · 第一個決定:不複製

量過:VRN 有 **37 個引擎家族**、**10 本規則樞紐**。
把規則抄一份進「整合冊」,就是開第二顆頭 —— 而且複本**一定比正本先過期**。

所以這本冊只記「**哪一層的正典在哪一支**」,規則本身留在原處。

```
VIA_VRN_LogicArchitecture_SSOT_v0100.json
  層 6 · 引擎指標 25 · 規則正本 10 · 今日裁定 5 · 待裁定 2
```

| 層 | 做什麼 | 正典 |
|---|---|---|
| L0 輸入識別 | 檔名 → 股號/券商/日期 | `SUP_MDL030` 檔名 SSOT · `SUP_MDL031` regex 橋 · `SUP_MDL015` 券商別名 |
| L1 擷取 | 非 OCR 優先,抓不到才退 OCR | **`VRN_ENG082` 中央邏輯庫(L30 擁有者)** + 7 條車道 + `SUP_MDL747/746` |
| L2 結構與知識 | 抽出來的字變成有欄位的東西 | `ENG072/073/074/063/064` |
| L3 驗證 | 「有值」不等於「對」 | `ENG083` 驗證矩陣 · `ENG076` 回歸閘 · `CGC_MDL141` 收尾閘 |
| L4 產出 | 給人看的那一層 | `ENG080` 四點文摘 · `ENG068` 每日簡報 · `ENG079` 控制塔 |
| L5 儲存 | **L90:正典=DuckDB** | `vdf_tw_market.duckdb` 的 `vrn_*` 七張表;`ENG081` 是 Parquet **派生**車道 |

規則正本另記 10 本:方法冊 `def01–21`(`vrn_method_kernel`)· 六欄規則(`SUP_MDL749`)·
財務邏輯 / 版面 / NLP / Markdown 四樞紐 · 階段別名 · 繁簡對照 · 基本資料欄 · Sheet 產出計畫。

## 二 · 第二個決定:冊是產物,不是手寫件

`via-vrnbook build` 由**樹**生成:glob 尾版解析每一個指標,再逐支**讀出檔頭第一句職責**。
不是我寫的(LL180:假設欄位名等於沒讀過那個檔)。解析不到任何一支就**整本不寫**
—— 半本冊比沒有冊危險。

## 三 · 第三個決定:冊要有守門員

索引冊最大的風險不是寫錯,是**寫對之後放著爛**。引擎一開新版號,冊上的 `tail` 就過期,
而它看起來還是一本冊,沒有人會發現。

```
$ via-vrnbook
=== VRN 邏輯架構索引冊 · 守門 ===
  指標 31 · 在位且為尾版 31 · **過期 0** · 不在 0
  [計] GREEN
```

守門抓三件事,每一件都在沙盒裡撞過一次:

1. 指標**不在了** → RED
2. 指標**還在但不是尾版了** → RED,並指名 `via-vrnbook build`
3. **待裁定項被改成已裁定** → RED（冊被動過手腳也是紅；LL90 裁定權在操作員）

格子 253 → **255 站**:工具健康一盞、冊新不新一盞。兩件事兩盞燈（批618 才學過一次）。

## 怎麼用

```powershell
via-vrnbook              # 守門:冊上指標還是不是樹上的尾版
via-vrnbook build        # 重建索引冊(引擎開新版號之後跑)
via-vrnbook --selftest   # 七檢
```

> `via-vrnbook` 是**新登錄**的短令(Register v0225)。你現在這個視窗點的是 v0224,
> 所以要先 `via-reload`(或重開視窗)才叫得動它 —— 沒 reload 之前它會是 not recognized。

驗環境用這一句(**逗號要加引號**;或者分三次打):

```powershell
via-rungate run --family 'vdf,vrn,vap'
```

## 七 · 同一批的第二件:一貼即用區的逗號

操作員照我在批621 給的句子打:

```
via-rungate run --family vdf,vrn,vap
  [FAIL] --family 只收 vdf|vrn|vap，不收 vdf vrn vap
```

**逗號不見了,變成空白。**根因不在他也不在引擎,在中間那層:
**PowerShell 裡不加引號的 `a,b,c` 是陣列**,`@args` 潑灑之後逗號就沒了。
而同一句寫在 `.ps1` 裡是 `'--family','vdf,vrn,vap'` 有引號 —— 所以 AllInOne 跑得好好的,
**同一個指令在兩個地方長得一樣、行為不一樣**,我在容器裡怎麼測都測不到。

`CGC_MDL137 v0107`:兩種長相都收(併成一個帶空白的字串 / 潑灑成多個 argv),
並把原因印出來;真打錯(`--family nope`)照樣紅,紅燈底下附這條說明。

> 潑灑成多個 argv 那半邊特別重要:`_arg` 只拿得到下一個 token,後面那兩個會變孤兒
> —— 那就是「只跑了 vdf 卻以為三族都跑了」的假綠。

我這邊的規矩也補一條:**一貼即用區凡是帶逗號的參數一律加引號**。
