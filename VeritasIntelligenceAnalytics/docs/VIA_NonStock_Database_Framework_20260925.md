狀態：規畫與現況對映；未宣稱新增資料表已部署。母系統 L90 的正式 DuckDB 與既有 VRN 寫入口仍為唯一正典，不另開一套正式庫。

操作員最新範圍（2026-09-25）：**目前只開個股研報線**。先完成個股與 VDF，再啟用非個股第二線；本輪 106 件混合文件屬隔離驗收，不是正式開通非個股。第二線先保留 DATE / FILENAME / BROKER 與來源原文，文字修復後再做 NLP；依主題數、證據密度與重複程度調整摘要粒度。非個股中的個股段落保留自己的實體關聯，不把整份強制改成個股報告。VCGC 統一掌握啟用、版本、來源與品質態。

## 整理方式

以「文件 → 段落／表格 → 重點 → 證據」收納，一份報告可以連到多個產業、國家、公司或金融商品。非個股報告沒有主要股票代號時，留空並標示不適用；不能從某個數字或第一家被提到的公司猜一個代號。

| 檢索分類（展示用，正式碼須對既有類型 SSOT） | 要抓的重點 | 常用維度 |
|---|---|---|
| 產業／主題 | 供需、價格、產能、技術變化、受益與風險 | 主題、產業、產品、區域、期間 |
| 總經／政策 | 指標實值、預測、政策事件、傳導方向 | 國家、指標、日期、情境 |
| 策略／配置 | 配置觀點、偏好、催化因素、失效条件 | 資產類別、區域、期限 |
| 市場日報／晨會／週報 | 本期事件與前次變化，拆成獨立重點 | 事件日、報告日、主題 |
| 訊息／新聞／Evernote | 誰在何時說了什麼、原文連結、後續待辦 | 來源、事件、更新時間、關聯實體 |
| 跨公司比較 | 每家公司各自的指標與觀點，不共用一個 ticker | 公司、指標、期間、單位、版本 |
| ETF／債券／其他商品 | 商品特性、利率、存續期間、曝險、成分 | 商品類型、代號、幣別、期間 |
| 未分類 | 原文完整保留，列待覆核理由 | 來源、檔名、候選類型 |

## 既有正典與擴充的邊界

| 邏輯資料 | 現有來源／落點 | 待補的契約 |
|---|---|---|
| 文件主檔 | `vrn_report_basic`：report_file、broker、report_date、report_kind、kind_reason | 文件内容雜湊、來源 URI、文件版本、重複件關聯 |
| 作者與機構 | `vrn_report_analyst`：institution、domain、zone、anchor_type、來源與信心 | 保留首頁左右小字區與檔名候選、衝突，不讓正文中的被評論公司取代券商 |
| 指標事實 | `vrn_report_metrics`、`vrn_report_financial` | 段落主體、幣別／單位／尺度、New/Old/Chg、原始欄位與頁座標 |
| 核對證據 | `vrn_report_crosscheck`，第二血統的原文／TableID／RowIndex／ColumnIndex | 每個重點連回來源片段；量不到與算錯分開 |
| 重點／觀點（規畫） | 沿用文件鍵與既有摘要，不把自由文字塞入財務數字欄 | claim_id、subject_id、predicate、value_text、direction、horizon、is_forecast、evidence_id、confidence、review_state |
| 實體關聯（規畫） | 連結既有公司、券商、產業與商品 SSOT | report_id、section_id、entity_id、role；一段多實體，不預設整份都屬同一家公司 |
| 來源連結（規畫） | 檔案 URI、網頁 URI、Evernote URI | provider、source_uri、external_id、updated_at、content_hash、fetch_state；未取得內文標 `LINK_ONLY` |

擴充先由正主 schema 註冊與 migration 定義，再於獨立庫副本驗證；本次沒有可存取的正式市場庫，未執行正式 migration。第二血統 Parquet/CSV/JSON 是測試產物，不回灌為另一份正典。

## 一個重點的最小資料

`文件鍵 + 段落鍵 + 主體 + 指標／事件 + 值或觀點 + 單位／幣別 + 期間 + 實際／預測 + 情境／版本 + 原文證據 + 來源連結 + 覆核狀態`。

New 與 Old 是同期間不同預測版本；Chg.% 是變動率。三者不可互相覆蓋，也不可把變動率放進營收或淨利金額。2026-09-25 的 Citi 真實產業報告已暴露並修復這個問題；跨公司段落的自動主體對映仍須另外驗證。

Evernote 連結本身不是已讀取內容。先存連結與來源狀態；取得授權內文後才切段、抽重點及建立證據。此輪沒有提供可驗證的 Evernote 記事內容，因此不列為已通過。

## 唯一 HTML 模板的展示

以既有 VIA_HTML_UI 的自定義模組呈現「文件／重點／數字／證據／待覆核」檢視；篩選文件類型、主題、日期、機構、實體與狀態。每筆重點可回到來源頁或連結。SYNCHRONIZER 只增補本模組、保留其他模組及使用者停用設定。

必要驗收：文件雜湊冪等；一份多主體不串公司；無代號不猜；無內容的連結不產生摘要；單位與預測版本不混；衝突雙方保留；每筆可追到證據；HTML 的 NODATA/REVIEW/FAIL 不顯示為完成。
