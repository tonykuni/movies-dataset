# 批672 · 活在四個地方的規格不是規格

操作員令:「以後跑完都要生成矩陣式報告 BY RICH,字小,優化矩陣排版規格」。

## 一 · 先看清楚要改的是什麼

「字小」聽起來是一個 CSS 數字。我去改的時候才發現要改**四個地方**:

| 引擎 | 批 | 自帶的字級 | 深淺兩套 | 手機寬 |
|---|---|---|---|---|
| CGC_MDL169 六域現況 | 批664 | 13px | 無 | 無 |
| CGC_MDL170 VDF 鏈 | 批667 | 13px | 無 | 無 |
| CGC_MDL171 全景計畫 | 批670 | 13px | 無 | 無 |
| CGC_MDL172 VRN 鏈 | 批671 | 12.5px | 無 | 有 |

四支各自帶一份 `css = ("body{background:#0f1116;...")`。
幾乎一樣,但**不是同一份**。

> 排版規格如果活在四個地方,它就不是規格,是四個人各自的習慣。

這四支是我在批664–671 之間一口氣做出來的——**是我自己種的四顆頭**。
每一支當下都「只是順手把頁排一排」,四次順手就變成四份規格。

## 二 · CGC_MDL173:它是排版,不是引擎

新支只做一件事:把「矩陣式報告長什麼樣」收成一份。
它不產生任何新資料、不判任何燈、不碰任何庫(自測第⑮檢就在咬這一條:
源碼裡不准出現 `duckdb`)。

「BY RICH」的意思是**表由 rich 畫**。這支不自己拼 `<table>`,
它給 rich 一個 `code_format`,讓 `Console.export_html(inline_styles=True)` 直接吐出整頁:
rich 畫矩陣,這支管頁殼。`inline_styles=True` → 零 class 依賴 → 零 CDN 零外連,`file://` 直開(L100)。

## 三 · 優化後的矩陣排版規格

| 面 | 鍵 | 值 | 為什麼是這個值 |
|---|---|---|---|
| 字 | matrix_px | **10.5** | 操作員令「字小」;原本四支 12.5–13px |
| 字 | matrix_line | 1.22 | 同一張頁多塞約三成的列 |
| 矩陣 | console_width | 200 | **寧可橫捲,也不要讓欄位換行——換行的矩陣對不齊,對不齊就不是矩陣** |
| 矩陣 | box | SIMPLE_HEAD | 只有表頭一條線;畫滿格子會把字擠小又更難讀 |
| 矩陣 | padding | (0, 1) | 上下 0 左右 1:密度來自這裡 |
| 矩陣 | num_variant | tabular-nums | 數字等寬才對得起來 |
| 頁 | one_file | True | 零 CDN 零外連;`file://` 直開(L100) |
| 頁 | scheme_toggle | **False** | 零彈窗律:頁上不長 UI,深淺跟系統走 |
| 頁 | mobile_scroll | matrix_only | 只有矩陣橫捲,頁身不捲 |
| 鍵 | md_source | caller | MD 由引擎產一份給頁;**JS 永不自己拼第二份**(L30) |

誠實六態 + 資料層兩態的顏色也收進同一份 `SPEC["states"]`,
四支引擎的燈從此是同一組色。

## 四 · 兩條車道,一個殼

有些矩陣是**逐列舉證**(VRN 那張是 81 份研報 × 7 欄),排成 `<table>` 比排成
預格式化文字好讀。所以規格給兩條車道:

- `page(console, ...)` —— rich 車道:矩陣由 rich 畫
- `page_html(body, ...)` + `html_table(...)` —— HTML 車道:呼叫端拼片段

**兩條車道共用同一個 `_head_foot()` 與同一份 `css()`。**
兩個殼就是兩份規格,操作員說「字小」的時候又要改兩個地方——
這支存在的全部理由就是「只有一份」,自測第⑲檢直接咬這件事。

## 五 · 兩個自我指涉的坑(當場踩到)

**① 宣告零 CDN 的那句話,被自己的零 CDN 檢當成 CDN。**
第一版我寫 `chk("零外連零 CDN", "cdn" not in h.lower())`,
結果頁尾那句「零 CDN 零外連」裡的 `CDN` 把自己照紅了。
量得準的不是「頁上有沒有這三個字」,是**有沒有真的往外指**:
外連屬性、`@import`、已知 CDN 主機名。(批664 踩過同一類:拿 regex 去讀 regex。)

**② 四支的 HTML 檢原本寫「頁上不准有 `<script>`」。**
接上三顆鍵之後那一檢全紅了——可是頁上的 JS **全內嵌、零外連**。
要禁的是往外拿:`<script src=` 才是外連,內嵌 `<script>` 不是。
順手把「三顆鍵在不在」也收進同一檢(L96 舉證能整份帶走:沒有鍵就帶不走)。

## 六 · v0101 刪掉的東西

`CGC_MDL172_VRNChainRunner_v0101` 把 v0100 的 `_CSS` / `_JS` 兩個常數**刪掉**了。

留著沒人用的那一份 CSS 不是「備份」,是第二份規格。
下次有人去改它,兩份就開始走鐘,而且走鐘的那一份**不會有人發現**——
因為它從來不被渲染出來。

## 八 · 一條新律

- **LL321** 順手排一次版不算做了規格。同一件事順手做四次,就是四份規格——
  而且你要等到有人說「字小一點」的那天,才會知道它散在四個地方。
