# 批637 · 剔除不是消失

## 你的令
> 本文部分標題沒有句號;根據字體大小粗體可分大中小標題、本文;
> 小字體不相關的頁尾(刪除);小字體不相關的後面附錄及它的標題(刪除);
> 大標題是帶著股票名稱及代碼的一句話。

## 這一單跟批636 正面衝突

批636 才剛立完 **「不刪除」**,而且用保全率 100% 釘住。
批637 指名兩類要刪。兩條都有道理:SUMMARIZE 不該讀免責聲明,但也不該有東西安靜不見。

**接法:剔除不是消失。**

| | |
|---|---|
| 被判要刪的 | 移出本文主體、**不進 SUMMARIZE** |
| 但是 | 留在檔尾「剔除區」,寫出是哪一條規則、字級多少、為什麼 |
| 保全率 | 從「留用 = 100%」改成 **「留用 + 剔除 = 100%」** |

> **操作員要拿掉東西的時候,拿掉的是它在流程裡的位置,不是它的存在。**
> 真的要它消失不見,那是另一道明示的指令,你說一聲(LL251)。

## 判準是量出來的

`gle.elements` 本來就有 `zone / weight / bold / italic / size / head`,`gle.body_font` 是內文基準(樣本 10.0):

```
{'zone':'TC','bold':'True' ,'size':'25.0','head':'VRN Fetch v4 — 設計審查會議'}
{'zone':'TL','bold':'True' ,'size':'14.0','head':'1 Action Items 行動項目'}
{'zone':'FULL','bold':'False','size':'10.0','head':'1 ControlCenter 的即時狀態燈號…'}
{'zone':'BC','bold':'False','size':'8.0' ,'head':'第 1 頁'}
```

| 層級 | 門檻 |
|---|---|
| **H1 大標題** | ≥ 內文 **1.8 倍** 且粗體 |
| **H2 中標題** | ≥ 內文 **1.25 倍** 且粗體 |
| **H3 小標題** | 粗體且不小於內文 |

門檻寫成**相對 `body_font` 的倍率**,不是絕對字級 —— 每一家研報的內文字級都不一樣,
寫 `size >= 18` 這種絕對值,換一家券商就整份判錯(LL252)。
而 `body_font` 缺席時**不推層級也不剔除**:沒有基準就不要假裝量得出來。

再加你點名的兩個訊號:

- **標題沒有句號** —— 字級等於內文又帶句號的,是本文不是標題
- **大標題帶股票代號** —— 多個大字候選時,命中代號的留 H1,其餘降 H2。**不是誰字大誰贏**

## 剔除兩條規則

| 規則 | 條件 |
|---|---|
| `DROP-FOOT` 小字體頁尾 | 字級 < 內文 0.9 倍 **且** 落在版面下緣三區(BL/BC/BR) |
| `DROP-APPX` 附錄與其標題 | 附錄起點詞之後、字級不大於內文(起點詞:附錄/附件/Appendix/免責/重要聲明/Disclaimer…) |

## 自審抓到一個真 bug

批636 的「CJK 硬斷接回」本意是修折行,但它**分不出折行與真的換行**:

```
投資論點
先進製程需求強勁。
```
→ 被接成 `投資論點先進製程需求強勁。` —— **標題當場消失**。

而且保全率**還是 100%**,因為字一個都沒掉 —— 掉的是結構。
畫面上只看得出「少了一行」。

補三道護欄:① 兩側都是 CJK ② **左行夠長**(折行只發生在行寬用完時,標題與短句本來就短)
③ 下一行是已知標題、或左行已經有句末標點,都不接。

> 一個修復規則上線之前,要先問它**會不會把正常的那一種也當成壞的**;
> 而且保全率量的是字、量不到結構 —— 兩種都要有人守(LL253)。
