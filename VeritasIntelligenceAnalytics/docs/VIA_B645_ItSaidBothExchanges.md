# 批645 · 手上只有一所,嘴上說的是雙所

## 接批644

批644 量到:價表 **TPEX 上櫃 892/892 齊,TWSE 上市 0/1,088 整所缺席**。
這一批往上追,根就在 `VDF_ENG054_TWDailyBackfill` 的 `fetch_listings()`:

```python
for mkt, (ep, suffix) in LISTING_EPS.items():
    r = net.http_json(ep)
    if r["state"] != "OK":
        print(f"  [FAIL] {mkt} 清單:…")
        continue                      # ← 一所失敗只印一行,另一所照寫
```

然後 `run()` 印的是:

```
[清單] 雙所+ETF 892 檔落庫(表 tw_listings 計 892)
```

**手上只有一所,嘴上說的是雙所,而且 rc 回 0(GREEN)。**

`if not listings` 只擋「兩所全滅」——
**剛好少一所,是它最擋不住的情況**:全滅會炸,全有會對,**少一半安靜通過**。

## 九檢為什麼沒抓到

```python
chk("③ 雙所端點冊(.TW/.TWO 後綴)",
    LISTING_EPS["TWSE"][1] == ".TW" and LISTING_EPS["TPEX"][1] == ".TWO")
```

**它驗的是端點冊上有兩所,不是兩所都回來了。**
冊上有兩所 ≠ 庫裡有兩所。九檢全綠了很多批,而整個上市市場一直不在。→ **LL275**

## 修法(`VDF_ENG054` v0105,11 檢)

| 改 | 內容 |
|---|---|
| 逐所實況 | `fetch_listings` 回 `(rows, per_market)`,每所帶 `state / n / why` |
| 不准自稱雙所 | 少一所印 `**單所落庫(缺 TWSE)** … TWSE=0 · TPEX=892`,並指名因由 |
| 誠實 rc | 少一所 → **rc=2(NODATA)**。宇宙不全是**缺料**,不是抓爆了 |
| 只增不減 | 已落庫的那一所照留(upsert 零刪除) |
| 失敗路要走過 | 檢⑩⑪ **注入假 net**,零網路下重現「TWSE 失敗、TPEX 成功」 |
| 檢數現場計 | 寫死的 `九檢` 會把新加的檢從帳上抹掉(LL213) |
