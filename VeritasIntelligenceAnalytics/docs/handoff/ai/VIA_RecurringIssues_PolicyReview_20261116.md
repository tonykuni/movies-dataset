## 二、建議列為政策的條目(草案,待操作員裁定)

| 草案 | 名稱 | 內容(一句話) | 與現有律 | 對應問題 |
|---|---|---|---|---|
| P-A | **交出前桌機模擬律** | AI 要操作員打的指令,交出前必須在容器以「Windows 路徑 + 使用者家目錄當工作目錄 + 落後分支」模擬一次;指令第一段一律自我定位倉根並檢查要跑的檔在不在,不在就先印 fetch / switch 的一行,不讓 python 去報 can't open file | 補強 L89 · L97 | #1 |
| P-B | **刪舊版先證明律** | 刪任何舊版檔之前,要在拿掉該檔的副本上**實跑尾版的每個動詞**(不是只跑自測或稽核探針);懶載入、名字釘死前版的鏈一律視為「被用到」 | 細化 L130 · L132 ④ | #2 |
| P-C | **要求的目標缺一不綠律** | 輸入名單(代號、族群、序列)裡任何一個在結果中不存在,總燈不得 GREEN,要逐項點名 | L57 誠實分母的具體化 | #3 |
| P-D | **掃描用語法樹律** | 判定「有沒有 import / 出網 / 橋」一律用 AST,不用字串搜尋;字串、註解、HTML 不算 | 補 L68 | #3(MDL002 誤報) |
