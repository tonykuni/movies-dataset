# VIA 多矩陣設計 v0101

適用：VCGC、VDF、VRN、VQG、VAP。設計日期：2026-11-07（Asia/Taipei）。

## 開啟

解壓縮後直接以 Edge 或 Chrome 開啟 `VIA_MultiMatrix_UI_Design_v0101.html`。不需要 Python、PowerShell、套件安裝、UI 伺服器或連線。檔案不包含外部 CDN；網路連線由 CSP 禁止。

1. 預設 M01 是八欄檔案／AST 主矩陣；點第 5 欄檔名 → def → 呼叫節點。AST 分支按需渲染，每批最多 50 個同層節點。
2. 點 U／I／S／R／C 按鈕查看測試欄位；M09 是完整階段總表。
3. M03–M07 展示大類 → 資料集／指標／圖形 → 欄位／參數。各層有候選編號、設計版號與時間欄。
4. 「載入本機掃描清冊」可選前版 Panorama v0100 的 `SOURCE_INVENTORY.json`。只能讀取陣列格式；不是 SUMMARY.json。上限 20 MiB／100,000 列。
5. 匯入模式不混入設計示例。沒有真 AST、工具接線、時間或測試收據時保留未知。PARSED、橋接標記不會轉成綠燈。
6. 「回到設計示例」清除匯入記憶體狀態；「匯出目前檢視」輸出 JSON 檢視快照，並不是執行收據。
7. 「詳細規格」可離線讀取完整設計；ZIP 內 Markdown 更適合交接與程式實作。
