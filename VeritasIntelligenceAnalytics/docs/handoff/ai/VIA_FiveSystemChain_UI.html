5｜測試與輸出

判燈四條:入口不在 = GRAY · 逾時 = GRAY 並記實際秒數 · rc≠0 = RED · rc 0 但沒印判決行 = YELLOW UNVERIFIED(rc 0 本身不是證據,同交接閘 target_marker_seen)。
判決行說 YELLOW 就留 YELLOW,不漂白成綠。總燈 = 五個之中最壞的那一個。
