## 真正的問題:那 25 份在報告上一個字都沒有

取料那一句是:

```sql
SELECT * FROM vrn_report_basic WHERE ticker IS NOT NULL AND ticker <> ''
```

然後摘要印「報告 46」。
**它不報錯、不變紅,看起來就是「只有 46 份」。** 讀的人看不出有東西掉了。

v0107 把分母攤開,而且分三態不分兩態:

```
[漏斗] sidecar 81 → 還原 .md 81 → 入庫 71 → 文摘 46 · 零正文空殼 8(rep_00, rep_01…)
[分母] 入庫 71 = 文摘 46 + 不適用 23(非個股;依 NA-01) + 型別未定 2(NODATA)
```

- **不適用** 依既有正本 `VRN_MatrixApplicability_SSOT`(批633 你那一批立的 NA-01)。
  本件**不自己判型別**(LL133 判定器不自判);那本冊缺席就一律當「適用」,**不假造 N/A**。
- **型別未定 → NODATA,不是不適用。**
  批633 在矩陣那邊正是把空型別當成「不是個股」,整欄被判成不適用。這裡不重蹈。

→ **LL267:凡是會縮小分母的條件,都要把被排除的那一群連同理由印出來。**
