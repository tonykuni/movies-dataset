## 30 秒上手 (Windows)

```powershell
# 1. 解壓縮後進入資料夾, 先用合成資料驗證安裝 (免網路, 約 1 分鐘)
.\launch.ps1 -Mode demo

# 2. 確認沒問題後跑真實資料 (會連 MOPS, 首次 36 個月約 20-40 分鐘)
.\launch.ps1 -Background      # 背景執行, 不卡住視窗

# 3. 只跑測試
.\launch.ps1 -Mode test
```

非 Windows 或想手動控制:

```bash
pip install -r requirements.txt
python -m twrevenue.cli demo       # 合成資料跑完整流程
python -m twrevenue.cli selftest   # 20 項內建測試
python -m twrevenue.cli run        # fetch -> analyze -> report
python -m twrevenue.cli groups     # 兩階層族群樹 + SSOT 驗證 + MOPS 核對
python -m twrevenue.cli breakout   # 真突破名單 + 被濾掉的假象對照組
```

## 這個版本 (v2.7) 的重點

**兩階層族群**: 12 大類 / 46 子族群 / 235 檔。半導體細分 15 個子族群、
AI 伺服器細分 7 個子族群 (AI OEM/ODM、AI 機殼/機櫃、AI 導軌/滑軌、液冷/水冷板…)。
矩陣三層展開 L1 → L2 → 個股。

三個治理決定:

1. **L1 加總依個股去重** — 3711 同在封測與 CoWoS，扁平加總會算兩次。
   去重保留角色最高者，龍頭不被降級；有測試斷言結果不得等於未去重值。
2. **`status` 欄取代單一 flag** — `flagged`(誤植) / `excluded`(規模稀釋) /
   `superseded`(已被細分取代)，一律保留列、只增不減。
3. **縮排只加在名稱格** — 加在整列 padding 會讓彈性欄被擠壓的量與縮排量在窄螢幕
   不再相等，後面每個數值欄橫移。順帶修掉兩個潛伏在舊區塊的對齊 bug。

## 品質驗證

- `selftest` **20 項全過** (代號 regex / MOPS 解析 / CSV 編碼 / 產業階層 SSOT /
  國際對照 / 週期六大類 / 族群 SSOT / **族群兩階層** / **L1 去重加總** /
  parquet 增量 / duckdb / URL 推算 / 公式 / 突破數學 / 突破 ground truth /
  突破反低基期 …)
- 版面: Playwright 座標量測，4 個矩陣 × 10 種寬度 (1440 → 360px)，
  **678 個格位錯位 0、零橫向捲軸**。
- 突破偵測內建 6 個 ground truth 案例，每次修改必須全中。

## 已知限制 (誠實揭露)

- **本沙盒環境連不到 MOPS** (台灣金融網域一律 403)，因此 `fetch` 的實際抓取
  **未在此環境端對端驗證過**；解析邏輯以真實 MOPS HTML 結構寫成並有單元測試覆蓋，
  但請在你的機器上先跑一次 `.\launch.ps1 -Mode fetch` 確認。
- 新增子族群的 role (L/P/G) 為**推論**，來源是財報狗題材標籤與媒體整理，
  非 VIA 原始策展；若有權威角色表，覆蓋這些列即可。
- `github.com/tonykuni/via-vdf-vrn` 仍為 404，權威族群表尚未取得。
- 月營收只反映營收面，不含毛利率/ROE。建議後續在 L2 子族群疊加獲利指標作第二確認。
- 週期股的價格/庫存/產能利用率不在 MOPS 月營收內，需另接資料源。
