VIA WorkOps · Consolidation Map

一頁式收斂地圖 — 該用哪個檔、照什麼順序

你現在有 4 個掃描器、2 個前端、一整個 Forge。這張圖把它收斂成 一條清楚的路。原則不變:你自己權限、只讀、本機、不自動寄、不監控別人。

1兩條路,擇一就好

Route A · 建議

檔案式(離線・零安裝)

掃描器(擇一)→ 匯出檔 → 拖進 Dashboard v6 → 追蹤信引擎。
雙擊即用,不裝 Python、不開伺服器。大多數人用這條。
Route B · 功能最全

伺服器式(需 Python)

跑 via_server.py → 瀏覽器開 index.html(即時 /api)。
功能多,但要維護 Python 環境與本機伺服器。進階才用。

⚠ 隔離區(維持只讀,別接進任何自動流程)
· Invoke-VIA-SupportiveCore-PromptInjection.ps1 — 你自己的 helper 已標記為「靜態稽核、不 dot-source」。別執行、別 import、別接自動化。
· via_rebuild.py — 有變更風險,永遠手動、逐次確認,別讓它自動觸發。

5一句話 SOP

每天:掃描(擇一) → Dashboard 看/評分/清單 → 匯出 recipients.csv → 追蹤信引擎建草稿 → 你檢視後親自按傳送 → 隔日 -Mode FollowUp 補追殺。
界線:你自己權限 · 只讀擷取 · 本機處理 · 不自動寄 · 不繞過 IT · 不監控同事。
