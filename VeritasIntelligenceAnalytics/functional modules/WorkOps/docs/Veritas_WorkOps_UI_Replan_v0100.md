## 四、產品化補篇(操作員產品化令 2026/08/09)

### 4.1 新進員工首跑精靈(Onboarding Wizard;10 面之外的一次性覆蓋層)

零技能情境:全新電腦(僅內建 PS 5.1)→ 雙擊 INSTALL_ONECLICK.cmd → 開板即進精靈。
每步只有滑鼠選項,無任何打字必填:

1. **環境驗收** — 讀 out/bootstrap_report.json + out/selftest_report.json,八步+五段
   逐項綠燈;有紅燈顯示「重跑部署」按鈕(複製指令)。
2. **Outlook 附掛** — 自動偵測桌面版 Outlook(COM 唯讀;IT 核准函=docs/IT_Approval_Letter
   正本,精靈附「複製給 IT 的信」按鈕);未核准前只跑本機 fixtures 演示模式。
3. **專案自動建構** — 首掃後直接出 WOP 卡片牆(87 案式),資料夾=分類基礎;
   關鍵字規則照令:產品名/代號=是,一般名詞=否;郵箱/URL 機構名入詞。
4. **資料夾更名建議(選擇題)** — 系統對「無代號資料夾」出建議名(含新編號);
   選項:a 採用 b 只記對照不改名 c 略過。編號一旦生成永不變;對方編號永不改只對照。
5. **控管表匯入** — 引導複製 docs/Strict_ControlSheet_AI_Prompt_v0100.md 提示詞
   → 丟任何 AI → 貼回八欄 CSV;違約輸出誠實 FAIL 重試。
6. **節奏確認** — 顯示 16:00 產草稿/次日 12:00 期限/下午僅急件(值來自
   watchtower daily_rhythm,可點「改時間」開參數檔)。

### 4.2 日節奏在板上的呈現

- 00 今日面加「節奏帶」:16:00 倒數 → 今日將產 N 封草稿;12:00 線 → 昨日已發未答
  名單自動列為逾期紅卡(下午僅 ⚡ 急件浮出,其餘收合)。
- 所有追蹤信問句一律封閉式:滑鼠可點(Outlook 投票鍵)或 a/b/c/d 單字母回覆;
  回信自動更新板況+確認窗;使用者若常選「其他」= 我方選項太弱,列入選項改進佇列。

### 4.3 錯誤互動鐵則

系統任何疑問一律選擇題(chips/abcd),永不開放式提問;每題附「其他」但以
「其他被選=選項設計失敗」為品質指標(進 05 準確度面統計)。

- 主管控管表回寫:only 匯出新檔(正本不就地修改),永不回寫使用者原 Excel。
