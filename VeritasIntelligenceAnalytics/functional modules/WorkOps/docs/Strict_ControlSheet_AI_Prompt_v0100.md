# 嚴格控管表 AI 提示詞正本 v0100(Veritas WorkOps)

> 操作員令(2026/08/09):使用者把自己的工作控管表 Excel 丟給「任何 AI」時,附上這段
> 預寫的嚴格提示詞;AI 產出標準七欄+對方編號 CSV,系統再讀 AI 的解讀結果。
> 鐵律:①編號一旦生成永不變;②對方(客戶/供應商)的編號不能改、只能對照;
> ③AI 只整理不發明 — 表上沒有的資訊一律留白,不猜。
> 用法:複製下方「提示詞正文」全文 → 貼給 AI → 附上你的 Excel/貼上表格內容。
> 產出 CSV 存成 UTF-8 後,即可被 identifier `sheet_normalize` / 板 `ConvertTo-StdSheet`
> 以 sheet_aliases(TheirCode 已入正本)無痛吸收。

---

## 提示詞正文(可直接複製)

```
你是資料整理員。我給你一份工作控管表(Excel/表格)。請把它轉成「一列一件事」的
CSV,欄位固定為以下八欄、順序不可變、欄名一字不可改:

ProjectCode,TheirCode,ProjectName,Owner,Status,Progress,DueDate,LastUpdated

嚴格規則(違反任何一條即為錯誤輸出):
1. 只整理、不發明:原表沒有的資訊留空白,禁止猜測、禁止補完、禁止改寫原文用語。
2. ProjectCode=我方(表主)自己的案件編號;找不到明確我方編號就留空,不可自創編號。
3. TheirCode=對方(客戶/供應商/來文方)的編號:PO 號、來文文號、客戶案號等。
   對方編號一個字元都不可改(不去零、不改大小寫、不改分隔符),原樣照抄。
   我方編號與對方編號絕不可互換或合併;分不清楚是誰的編號時,放 TheirCode 並在
   ProjectName 末尾加註「(編號歸屬待確認)」。
4. ProjectName=事項名稱,照抄原文;可去除前後空白,不可翻譯、不可縮寫。
5. Status 只允許五值之一:進行中/已完成/卡關/需要協助/未開始;原文語意對不上
   五值時照抄原文(系統會再判讀),不可留空(原文有寫的話)。
6. Progress=百分比數字(0-100),原表沒有就留空;DueDate 與 LastUpdated 一律轉為
   yyyy-MM-dd,只有年月時取當月最後一日,無法確定日期就留空。
7. 一列一件事:原表一格塞多件事時拆成多列,ProjectCode/TheirCode 照抄到每一列。
8. 合併儲存格向下填滿(承上者補上一列的值)。
9. 輸出只有 CSV 純文字:第一列為欄名列,不要任何說明文字、不要 markdown 圍欄、
   不要總結。欄值含逗號時用雙引號包住。
10. 最後自我檢查:列數是否=原表事項數?TheirCode 是否逐字元與原表一致?
    有任何一欄是你推測出來的嗎?若有,改回空白再輸出。
```

## 系統側接收約定(內部,不隨提示詞給 AI)

- 八欄=板 `$SheetAlias` 七標準欄+TheirCode;AI 輸出即是標準欄名,`sheet_normalize`
  零轉換直收;就算使用者拿到的是別家 AI 的變形欄名,同義字表仍可對齊。
- TheirCode 全鏈唯讀:identifier/板只顯示、只對照(THR/WOP ↔ TheirCode),永不寫回、
  永不當歸戶鍵(歸戶鍵=我方 ProjectCode/WOP);對照關係存 out/ 側車,原 CSV 不回寫。
- Status 非五值者走 M3 關鍵詞層再判;隱性阻塞詞(等/尚未/卡/pending…)照樣觸發
  板①頁紅籤。
- 若 AI 產出違規(欄名不符/多說明文字),系統誠實報 FAIL 請使用者重貼提示詞,
  不做模糊修補(嚴格契約=可信輸入的前提)。
