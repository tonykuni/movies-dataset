SmartAsset AST 編號體系

VIA 統一的智慧資產編號系統，所有子系統的 Class、Function、Library 都使用相同的編號格式，確保跨系統的資產追蹤與定位。

編號格式

{DOMAIN}-{KIND}{SEQ:03d} DOMAIN (功能域) KIND (資產種類) SEQ (三位流水，跨區塊累計不重設) ───────────── ─────────────── ────────────────────────────── NET 網路工具 C Class 001 → ∞ 永不歸零 ACC 加速器 F Function CORE 核心邏輯 L Library (第三方封裝) IO 輸入輸出 UTIL 共用工具 COM 商方整合 DATA 資料模型 CFG 設定/Schema 範例: NET-C001 → 網路工具 Class 001 ACC-F003 → 加速器 Function 003 COM-L001 → 商方整合 Library 001

SHA1 資產 ID

每個檔案級資產使用 SHA1 前 10 碼作為唯一 ID：AST-{SHA1_10}，由相對路徑計算而得。

錨點插入格式

# ▸▸▸ INSERT:{ANC-X}:{DOMAIN}-{KIND}{SEQ} ◄◄◄
