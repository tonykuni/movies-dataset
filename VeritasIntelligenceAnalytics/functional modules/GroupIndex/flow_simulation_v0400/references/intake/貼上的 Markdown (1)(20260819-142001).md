## 方法論 — 你的五個問題

**① 代表性**

代表性 rep\_score=追蹤直接度·AUM·流動性·實體複製·主掛牌綜合;選 rep 最高且在 FIS 宇宙有真實資料者,否則標記待加入。

**② 推估總金額·有效性**

代表/成分 ETF 之 NetFlow$ = ΔShares×NAV(申購贖回=一級市場真實流);指數隱含總流 ≈ ΣNetFlow$ / 覆蓋率cov。ETF 流是樣本與前瞻代理,非全市場真值。

**③ 力道·方向·交易金額**

方向=FIS 符號(申購+/贖回−);力道=|FIS|(0–100,已標準化);交易金額=NetFlow$ 與隱含總流並列。

**④ 標準化**

有機流=NetFlow/AUM\_{t-1} → 穩健 z(中位/MAD,σ=1.4826·MAD)→ FIS=100·tanh(z/κ)∈[−100,100];跨區另做 FX 調整。

**⑤ 驗證方法論與流程**

證偽優先\:leaky-vs-clean Rank-IC gap、null≈0、OOS、CPCV;並以 truth 源(ICI/TWSE T86/北向/EPFR)交叉驗證 ETF 隱含流的領先性與覆蓋率穩定度。

## E3 · 計算規格 — 去當沖真流 + data-quality 折扣

首選存量差分(當沖自動抵消);周轉類才扣當沖成交值;當沖比 + 維持率脆弱度折成信心權重,接 FIS data-quality-adjusted 變體。

| 步驟公式說明              |                                                         |                                              |
| ------------------- | ------------------------------------------------------- | -------------------------------------------- |
| ① 去當沖真流(首選)         | 真流 = Σ Δ存量 = 買賣超$(T86) + Δ融資餘額(MI\_MARGN) + ETF NetFlow | 存量差分:當沖當日買=賣、EOD 淨部位變動=0 → **自動抵消**,免額外扣     |
| ② 周轉類才扣當沖           | 非當沖成交值 = 總成交值 − 現股當沖值 − 資券當沖值                           | 僅用量能/OFI 類指標時才需;當沖兩腿都計,去噪注意雙邊                |
| ③ data-quality 折扣權重 | w\_dq = 1 − clip(當沖比, 0, cap)                           | 高當沖比 → 低信心;接你 FIS 的 data-quality-adjusted 變體 |
| ④ 品質調整 FIS          | FIS\_adj = FIS × w\_dq × f(維持率脆弱度)                      | 同一 +買賣超,法人現金 vs 散戶低維持率槓桿,持續力天差地遠             |
| ⑤ churn vs 真吸籌 對照   | 爆量 & Δ存量≈0 = 純 churn;量平 & Δ持股↑ = 真吸籌                    | 量能不等於流入;以 Δ存量為準                              |

三個提醒:買賣超為**zero-sum 再配置**(全市場加總=0);外資空單多走 **SBL 借券賣出**不入融券,券資比會漏法人空方;**融資維持率為衍生估計**,非 TWSE 原生欄位,須以融資餘額成本基礎推估市場均值。
