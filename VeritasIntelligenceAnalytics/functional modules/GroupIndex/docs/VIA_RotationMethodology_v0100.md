# VIA 族群輪動×資金流方法論冊 v0100(批154)

**紀律紅線**(全冊適用):
1. 零固定參數——一切門檻=滾動分位/滾動分布導出;窗長不擇一,以多窗 {20,60,120} 並列報告。
2. 全數值非分數——報 N、平均遠期報酬、勝率、null 均值、p 值等原始數字,不造合成評分。
3. 評估窗=2026-01-02→庫內最新(v0202 正式基準紀律);暖機=2025-01-02 起。
4. 回測穩健性=walk-forward 對半(2026-01→04 / 2026-05→最新)+震盪日(|大盤日報酬|>滾動 252d q95)含/排雙報。
5. 誠實資料階梯——每一指標標明所用資料層(真值/PROXY/PENDING),資料到位自動升階。

## S1 結構確認:主動式台股 ETF 買賣 ⊂ 投信買賣超
台灣制度面:投信基金(含主動式 ETF)之集中市場買賣計入 T86「投信」買賣超。
實證法:對每一有前快照之 portfolio_date,以 Σ(各主動 ETF 對個股之持股 Δ 股數)
對照同日 tw_chip_inst.trust_net(股),報:
- 符號一致率(ETF Δ>0 ⇒ trust_net>0 之比率)
- 量級包含率(|ETF Δ| ≤ |trust_net| 之比率;「屬於」= ETF 面為投信面之子集)
- 橫斷面相關(Δ 股數 vs trust_net)
資料階梯:持股快照現僅 2 日(批131 起每日累積);首月為初證,N 隨日增。

## S2 金流佔比指標(操作員公式)與動態規模分級
`share_i,t = (val_i,t − dt_i,t) / (Σval_t − val_2330,t − DT_mkt,t)`
- val=逐股成交值(真值層=tw_trading_daily,ENG057 回補中;缺日 PROXY=close×volume 逐列標記)
- dt_i=逐股當沖成交值(TWSE 端點 WAF=PENDING;先設 0 並標記)
- DT_mkt=市場當沖成交值(tw_daytrade_market 可得日採用,缺日設 0 並標記)
- 台積電(2330)自分母剔除=避免單一巨檔壓縮全市場佔比刻度;2330 本身逕判 LARGE。
分級:60d 滾動中位 share → 逐日橫斷面滾動三分位(動態,無固定門檻)→ LARGE/MID/SMALL。
有效性數值:逐日分級延續率、月遷移矩陣、與成交量位階單調性(Spearman)。

## S3 族群性證據(關聯・連動・領先)
對 v0202 名冊 39 族群,各報:
(a) **逆勢集體事件**:大盤(^TWII)日報酬<0 且族群等權報酬>0 之日數;
    強型=全員上漲日數。null=同規模隨機偽群 ×1000 抽樣分布 → 報實際數、null 均值、經驗 p。
    (操作員語意:大盤跌全跌、該族群集體漲=連動性最強證;成因或有人為,證據性不減。)
(b) **殘差相關抬升**:成員報酬對 ^TWII 滾動迴歸取殘差,族群內兩兩相關中位數 vs 偽群 null → 抬升值+p。
(c) **領先性**:取自輪動核心最新 TW 實跑 role_snapshots(BestLag/PermutationPValue)聚合——核心複用零重建。

## S4 技術分析組合定義冊(全滾動制)
- **超漲**:20d 累積殘差報酬 > 自身 252d 滾動 q95;**超跌**:< q05。
- **背離(空)**:價創 60d 滾動高 且 20d 動能 < 自身 60d 滾動中位;**背離(多)**鏡像。
- **大盤例外旗標**:^TWII 同日同態 ⇒ 該態標 MARKET_DRIVEN(非個股特異;操作員問「中間有沒有例外是被大盤影響」之定義化)。
回測:各狀態之 5d 遠期報酬 N/均值/勝率 vs 無條件基準,雙窗 {20,60} 並列。

## S5 意外事件與穩健性
意外常在:不預測、不剔除單一事件;以震盪日(|^TWII|>滾動 q95)含/排雙報+walk-forward 對半一致性(同號=穩)呈現方法對意外之敏感度。

## S6 全球資金流比較性(ETF×評價×利率×風險程度)
- 風險程度:各標的 60d 滾動年化波動+滾動最大回撤 → 逐日橫斷面滾動三分位=動態風險層(LOW/MID/HIGH)。
- 資金面比較性:成交值佔比(同 S2 式、全球宇宙、TURNOVER_PROXY 層)之 Δrank=跨商品可比之資金傾斜訊號;
  評價(etf_stats trailing_pe)+利率(US10Y)+匯率=既有因子面(批153)。
- 價格輪動可比較性=核心五指數 base-100(V08 檢已證)。
