13｜金額政策與驗算方法
只把貨幣千元轉百萬元；股數、EPS、百分比、倍數、天數不是貨幣百萬元，不可一起除 1000。
來源整數格式 → 最終金額取整數；來源有小數 → 最終金額取一位小數。用 Decimal + ROUND_HALF_UP，不使用 Python float 的銀行家捨入當最終規則。
合成例：1234 千元 → 完整精度 1.234 百萬元 → 整數來源最終 1；1250.0 千元 → 1.2500 → 小數來源最終 1.3；(1500) 千元 → -1.500 → -2。來源數值仍保留在別欄。
本批實際來源中千元格數為 0；千元規則由合成政策測試驗證，不能宣稱有真實千元報告實測。
原印 n 位小數通常形成 x ± 0.5×10^(-n) 的顯示捨入區間；金額縮放時，區間也同步縮放。加減法及乘除法傳遞區間，檢查計算結果區間與來源結果區間是否重疊。
區間方法用於辨識顯示精度下可相容的數字，不證明未印出的底層精確值相同。不加固定寬鬆容差把明顯差異放行。
分母為零或區間跨零時，應列為不可算／覆核，不能產生 Infinity 再標 PASS。不得混用不同年度、不同預估版本、單季／累計或不同單位。

18｜失敗時如何定位
MISSING_FILE／FILE_SHA256_MISMATCH：先看路徑／解壓完整性，從原包重解到新目錄；不要重算 manifest 把未知修改認列為正確。
REFERENCE_MANIFEST_PIN_MISMATCH：基準版本或內容不同。停止，辨識版本；不要移除 pin。
SOURCE_SHA256_MISMATCH：來源報告不是已校準版本。保留新原檔並走新版面校準。
找不到引擎／來源資料夾：檢查 --dispatcher-root、--input-root 及根目錄結構，不要讓程式默默改讀其他正式資料。
OUTPUT_ROOT_OVERLAPS_SOURCE_ROOT：換一個獨立 runs 輸出目錄，保留原檔。
Fresh source validation requires review／SOURCE_GLYPH_CUT：查看表格 id、來源頁、row_index；先檢查邊界與逐欄座標，再決定是否需要更重工具。
FACTS_DIFFER_FROM_VERIFIED_REFERENCE：逐格比對 VALUE_RAW、PERIOD、UNIT、VALUE_CHECK_DECIMAL；不能只看最終金額是否相同。
ROUNDING_POLICY_MISMATCH：查 SOURCE_DECIMAL_PLACES、SCALE_FACTOR、ROUNDING_STAGE，禁止在驗算前捨入。
CSV／Parquet／Excel 不符：查 UTF-8 編碼、空值與字串型別、欄位名、表格列序，禁止使用靜默轉型把異常吞掉。
pip／import 問題：確認專用環境為 Python 3.12、requirements 版本與 pip check，留 install.log；不要在正式環境反覆升降版。
PDF 字型問題：保留 NotoSansTC-Regular.ttf，重新產生 PDF 並檢查文字與實際畫面。
RUN.lock 競爭：另一份同入口可能仍在執行。等待或檢查其 RUN_STATUS，不得 Stop-Process；正常或異常離開都會由 finally 釋放 OS 鎖。
舊成果仍在：只看本次新的 run_id 與本次 RESULT_VERIFICATION，不得拿上一次 PASS 當本次通過。

19｜刻意錯誤測試原則
在交接根目錄執行：
python -X utf8 .\tools\TestVerifier_v0108.py --receipt .\runs\negative_tests.json
預期 status=PASS、rejected_cases=6；這代表六項錯誤均被拒絕，不是錯誤資料被接受。
只在臨時副本或記憶體測試，不改 pack 基準：例如改一格 VALUE_NUMERIC、把頻率改 QUARTERLY、製造重複唯一鍵、把 GS 的 -- 補成 0、修改一個引擎檔，驗證器必須拒絕。
測試後丟棄臨時副本，不得把負面測試的數字寫回正式輸出。測試失敗要帶有明確原因與 exit code 1；缺依賴必須回報 FAIL，不得跳過之後宣稱完整 PASS。
