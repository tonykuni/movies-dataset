團泰期賃國泰證券子公司聯陽 3014 TT ( 電子上游–IC 設計 )
EC/IO 續攻城掠地,Type-C PD 額外加分投資與評價
1.
聯陽庫存與存貨週轉天數領先同業落底,3Q23 營收上修至季增2- 3%,4Q23 步入淡季，估營收季減14%。
2.
聯陽營收80%與NB/PC 連動,4-5 年的換機週期已屆，且NB 有感升級，估2024 年全球NB 出貨量將年增5%至1.79 億台，重返成長。
3.
Intel 新CPU 帶動EC/IO 規格升級，有助整體混合 ASP 持穩，新品Type-C PD/HDMI 2.1 retimer 挹注，估毛利率持穩在50-55%上緣。
4.
估2023-2024 年EPS 9.53 元/11 元，年增26%/年增15%,長期現金股利配發率超過80%,目前股價隱含2023-2024 年現金殖利率超過5%,常態本益比10-17 倍，給予歷史上緣17 倍，目標價187 元，初評買進。
重點更新2024 年NB/PC 回歸成長主要受惠者之一2024 年NB/PC 重回成長，加上產業大者恆大，聯陽市占持續提升，帶動EC/IO 與高速影音介面相關晶片出貨量提升，而Intel 推出新世代CPU(Meteor Lake),PC EC/IO 規格升級，亦有助整體混合 ASP 持穩，新產品USB Type-C PD/HDMI 2.1 retimer 即將推出,1H24 開始貢獻營收。
高毛利Type-C PD 新業務額外加分聯陽正式通過Intel 與AMD USB Type-C PD 認證，透過NB ODM 進到供應鏈，目前聯陽支援PD 3.0/3.1 協定，鎖定PC/NB 跟Docking,產品主要在聯電8 吋廠投片，相較於美商具較高性價比，將分食德儀跟Cypress 市占，估2024 年聯陽PD 新業務至少可拿10%以上市占，初期貢獻營收3%。
聯陽EC/IO 市占率逐年提升EC/IO 主要透過LPC 排線與CPU 溝通，主要功能是做鍵盤控制/觸控板/電源管理/風扇控制/電池管理等,2019 年底新冠疫情爆發前，聯陽的EC/IO 市占率約35%,疫情期間提高至40%,推估目前在桌機Super I/O 晶片及NB EC 晶片市占率已各提升至45-50%及40-45%,持續分食美商市占。
