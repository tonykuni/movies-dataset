全台(3038) EDT的產品策略核心:由 Touch Display升級成為UMI (User Machine Interface) Solution。
今天的顯示器，已不再只是資訊的呈現工具。當我們加入智慧感測、控制核心、軟體架構與整體結構設計，它已經躍升為一個真正能與使用者對話的『人機介面解決方案』。這就是我們轉型的方向，也是我們創造差異化的關鍵。
UMI (User Machine Interface) Solution。
未來手機=AI個人節點(Device)+雲端推論中心(Cloud)。
Elon Musk 的論述指向一個核心邏輯:個人裝置將退化為I/O節點(Input/Output Node)
(a). 不主導運算。
(b). 不依賴 OS、App。
(c). 行為由AI理解、生成、推送。
(d). 裝置只負責「感知」、「呈現」、「小量邊緣推論」。
這意味著:UMI不再只是介面，而是AI與人之間最關鍵的「通道」。
適應AI未來情境的預測:Elon Musk在Joe Rogan最新Podcast節目表示，人類娛樂與溝通方式將被徹底重塑,「傳統意義」上的手機將走入歷史。「未來」的手機不再仰賴App與作業系統，只是AI推論(inference)的邊緣節點，用於顯示與收音，核心運算則在雲端AI之間進行，能預測使用者的想法與需求，即時生成內容。
有關軍工的產品，還有無人機的部分，今年都是生產，明年會出貨。
