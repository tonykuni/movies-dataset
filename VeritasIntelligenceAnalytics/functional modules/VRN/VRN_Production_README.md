## Pipeline Architecture

```
                      ┌─ Phase1 ────────────┐
                      │                     │
  Input → MDL001 → MDL002 → MDL003 ────→ MDL006 (reconcile) ──┐
  PDFs    Convert   Layout   Restore       phase1==phase2?     │
              │       │                                        │
              │       └─ Phase2 ──┐                            │
              │                   │                            │
              │       MDL002 → MDL004 (OCR tables) ─→ MDL006 ─┘
              │                 → MDL005 (OCR text)            │
              │                                                ▼
              ▼                                          MDL008 (triangle
       MDL001_StockReportPipeline                         cross-validate
       (alternate full-stack pipeline)                    report ↔ API)
                                                                ▲
                                                                │
                                                   MDL007 (MOPS + TWSE
                                                    + yfinance API)
```

**Phase1 path:** Higher fidelity. Uses layout-restored tables from MDL003.  
**Phase2 path:** OCR-based fallback for image PDFs. Uses MDL004 (tables) + MDL005 (text).  
**MDL006:** Reconciles Phase1 vs Phase2 — agreement = system internally consistent.  
**MDL007:** Pulls "ground-truth" data from official sources (MOPS = 金管會, TWSE/TPEX = market, yfinance = consensus).  
**MDL008:** Triangulates the report-extracted values against MDL007 API values.

## v1.1.0 Optimizations (applied to MDL001/002/006/007/008)

Each module gained these 6 optimizations while remaining 100% backward-compatible:

| # | Optimization | What changed |
|---|---|---|
| **P1** | DocCache (where applicable) | Open `fitz` + `pdfplumber` once per PDF, share across all extractors |
| **P2** | Page-level parallel | `ThreadPoolExecutor` over pages (MDL002 only) |
| **P3** | BatchBuffer + DuckDB | Worker-side push to lockless buffer, single-threaded flush |
| **P4** | Pre-compiled regex pool | Module-level `re.compile()` cache (MDL002 only) |
| **P5** | Polars-direct exports | DuckDB → Polars → Parquet/CSV (avoids pandas materialization) |
| **P6** | 4-phase Self-Verify HTML | Per-module VIA Visual Lock health report |

Measured speedup (MDL002 against test PDFs): **2.8× overall / 4.5× per-PDF**.
