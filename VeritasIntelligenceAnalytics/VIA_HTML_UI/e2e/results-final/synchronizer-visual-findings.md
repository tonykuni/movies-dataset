# SYNCHRONIZER reference-light visual findings

The SYNCHRONIZER now shares the central UI reference palette: light gray-blue page, white panels, gold primary action and section marker, green healthy states, yellow warning states, red danger states, and compact typography. The seal remains transparent and borderless.

The 1440px view keeps two-column panels and dense management controls. The 390px view switches to a single-column flow with readable controls and no horizontal overflow. Chromium loading produced no page errors.
