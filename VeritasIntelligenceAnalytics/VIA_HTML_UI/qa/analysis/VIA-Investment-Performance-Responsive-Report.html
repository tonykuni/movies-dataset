工程優先順序

依目前數據的改善建議，不代表正式 SLA 承諾

1. 降低中央 UI 首屏成本

優先壓縮嵌入式品牌圖像，並延後非首屏的活動流、拓撲細節與次要面板。中央 UI 檔案約為 SYNCHRONIZER 的 20.86 倍。

2. 建立可重複性能基線

固定瀏覽器與硬體，對冷啟動與暖啟動各執行至少 10 次，補充 LCP、JS heap、長任務與匯出時間，並改用中位數與 P95。

3. 優化 Hub Pipeline

投資研究的 Hub Pipeline 約占 CI 時間 74.59%。優先檢查重複初始化、檔案掃描與產物寫入。
