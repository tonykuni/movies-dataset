# VIA｜市場風險引擎 · 標準化計分規格 v001

> 承接《最終觀察參數登記表 v001》的 9 維度。本篇解決兩件事：**標準化**（統一計分尺、不寫死絕對值）與**健全性**（防爆點、防缺漏、防抖動）。
> 評分骨架仍為 Dragon-9：9 維度 × 3 級 × 權重 → Σ → 25–75 → 25–41 低 / 42–58 中 / 59–75 高。
> 核心戒律（來自附錄 A 教訓）：**任何絕對數字都不 hardcode**；一律轉成「對滾動窗的相對位置」。

---

## 一、共用標準化方法（所有維度共用同一把尺）

### 1.1 兩條標準化路徑
每個觀察參數先歸類為「連續型」或「事件/邏輯型」，各走一條標準化路徑：

**A. 連續型 → 相對位置**（融資餘額、乖離率、買賣超金額…）
- 標準轉換擇一：
  - **百分位 `pct`**：今值在滾動窗內的百分位（0–100）
  - **穩健 z 分數 `z`**：`(x − median) / (1.4826 × MAD)`，用中位數/MAD 而非平均/標準差（抗離群）
- 滾動窗標準集：**20 / 60 / 120 / 242 / YTD**（沿用你的成本線窗）。預設用 **242 日**，快窗 20/60 供加速度判定。

**B. 事件/邏輯型 → 布林旗標**（創歷史新高、假下降偵測、監管缺口…）
- 直接產生 0/1 旗標，或多條件 AND/OR 組合成一個複合旗標。

### 1.2 統一分級帶（1/2/3 級對所有維度一致）
| 級 | 連續型（擇一達標） | 事件型 |
|---|---|---|
| **1 低** | `pct ≤ 70` 或 `|z| < 1` | 無旗標 |
| **2 中** | `70 < pct ≤ 90` 或 `1 ≤ |z| < 2` | 單一旗標成立 |
| **3 高** | `pct > 90` 或 `|z| ≥ 2` | 複合旗標成立（≥2 條件） |

> 這把尺一致套用到 9 維度——這就是「標準化」。維度差異只在「用哪些參數、哪個窗、是否累積」，不在分級門檻。

### 1.3 累積性維度的標準累加器（D1/D3/D5）
標記為累積的維度，級別不看單日，看**累積壓力**：
- 標準累加器＝**20 日內「日 z ≥ +1」的天數** 或 **20 日 z 之和（EWMA 衰減 λ=0.9）**
- 分級：累加器 `pct ≤70 →1、70–90 →2、>90 →3`（同 1.2 尺）
- 意義：新因子今天不顯著但持續累積 → 分數會逐步爬升；舊因子單日爆一次但不持續 → 不會誤判為高。

## 二、健全性規則（護欄，全維度強制）

| # | 規則 | 目的 |
|---|---|---|
| R1 | **Winsorize**：原始輸入先夾在 P1–P99（或 ±3σ）再計分 | 防 6/24 這種單日爆點污染基準線 |
| R2 | **滾動基準、零 hardcode**：所有門檻都是對窗的 pct/z，禁用絕對數字 | 附錄 A 核心教訓（不寫死 2,525 / 8,134.8 億） |
| R3 | **最小覆蓋率閘**：維度需 ≥70% 參數有 V/M 級資料且窗涵蓋最新交易日，才計分；否則排除並記旗標 | 資料不足不假裝有分數 |
| R4 | **確認法則**：級別要升到 3，需該維度 ≥2 個參數同向達標 | 防單一參數假高 |
| R5 | **遲滯 Hysteresis**：級別翻轉需訊號連續 ≥2 個觀測點維持 | 防抖動/whipsaw |
| R6 | **新鮮度守衛**：窗未涵蓋最新交易日 → 該維度信心降級、標 stale（現況窗卡在 6/16） | 對應 VDF v003 P0 |
| R7 | **守恆/合理性檢查**：融資日變動＝前日＋增減；外資現貨/期貨方向一致性；背離時記旗標 | 抓資料錯誤與矛盾 |
| R8 | **缺值＝floor(1)、不靜默丟棄**：缺的參數以最低級 1 計入並標記 | 保守、可稽核 |
| R9 | **保守預設**：不可計分的維度**不灌入** breadth 分母；headline 用 verified_score | 寧可低估、不誇大 |

## 四、聚合與三分數（沿用，補標準化細節）

- 維度級 → `Σ(級 × 權重)`，範圍 25–75，分帶 25–41/42–58/59–75。
- **三分數併呈**（R9 保守）：
  - `breadth_only`：只納入通過 R3 的維度，分母隨之縮小
  - `verified`：只用 V 級資料的維度（今天 = D6/D7/D9 + D1/D2/D4 的 V 部分）
  - `data_quality_adjusted`：各維度乘資料折扣 `V=1.0 / M=0.8 / P=0.5 / X=0`
- 因子生命週期：每參數標 `生效中/監控中/衰退中`，只增不減。

## 五、兩個 worked example（標準化＋健全實際長怎樣）

**例一 · D1 融資（連續＋累積＋護欄）**
1. 取兩市融資餘額日序 → R1 Winsorize P1–P99。
2. 算今值對 242 日窗 `pct`；算 20 日「日z≥+1 天數」累加器。
3. 若 `pct>90` **且** 累加器 `pct>90` → 參數 3 級；R4 需再有第 2 個參數（如單日增額 z≥2）同向才確認維度 3 級；R5 需連 2 日維持才翻上去。
4. 官方逐日未補齊 → R3 只給 M 級 → 進 `data_quality_adjusted` 打 0.8，`verified` 不計。

**例二 · D6 失業率「假下降」（事件複合旗標，零 hardcode）**
- 規則：`ΔUR < 0` 且 `ΔLFPR < 0` 且 `家庭就業 Δ < 0` → 複合旗標成立 → **直接 3 級**。
- 6 月：4.2%↓、勞參 61.5%↓、家庭 −507k → 三條件全中 → D6 該參數判 3 級（失業率下降是失真、不是轉好）。
- 完全不依賴「4.2% 是高是低」的絕對判斷，只看三個方向的邏輯合取——這就是標準化＋健全。
