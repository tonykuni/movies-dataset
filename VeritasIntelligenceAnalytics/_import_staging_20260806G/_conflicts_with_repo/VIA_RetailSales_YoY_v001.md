- 名目 +6.9% YoY，但**不調整通膨**；實質月增僅 +0.4%（4 月更是「幾乎全靠漲價」）。
- 加油站 +3.4% 主要來自**油價非量增**（3 月汽油曾 +15.5%）。
- **餐飲年增從 +6.4%（2025/5）降到 +2.7%**、電子連 7 月增後轉跌 → **非必需/服務消費在軟**。
