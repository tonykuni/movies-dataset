系統發展路徑 / Development Roadmap

根據附件矩陣與三層命名憲法，新版系統頁面要把「設計說明」變成「治理儀表板」。

Next Architecture
Phase 01

VIA Infrastructure Lock

鎖定 VIA_SSOT、VIA_Prompt、VIA_Methodology、VIA_CommandCenter、VIA_ReviewMatrix 為基礎建設，不再混入金融應用。

Phase 02

Functional Core Protection

VDF / VRN / VAP 不改名，只做 alias 與 UI label。所有舊檔與 pipeline 保持相容。

Phase 03

Application Consolidation

Market / Risk / Macro / Strategy / Weekly / Pulse 全部收斂成 Veritas 應用分析主模組。

Phase 04

Matrix-Driven UI

每個頁面都能直接讀取 Matrix：Overview、Duplicate、Parameter、VRN I/O、Stage I/O、Risk/Action。

Final Rule / 最終規則： VIA* = Infrastructure；VDF / VRN / VAP = Functional Core；Veritas* = Application Analytics. This one-page design keeps the product beautiful, but more importantly keeps the architecture governable, deduplicated, and evidence-driven.
