# 隔離區策略(Quarantine = 名冊策略,不是沙盒)

**隔離區是名冊策略,不是沙盒。** 全景**不呼叫**隔離區裡的引擎,也**沒有把它們的檔搬走**;別人若直接匯入那些檔,名冊擋不住。本技能只保證「**這次全景檢查不會順手用到它們**」,不保證這台電腦上沒有別的指令去用。

全景真正核對的**只有四件事**(通用化:N 個名字、K 個組):

| # | 核對 | 燈 |
|---|---|---|
| Q1 | 名冊裡的 N 個名字**都在鎖檔**(`lock` 集合 ⊇ `quarantine` 集合) | 缺任一 → RED |
| Q2 | 每個名字**都還有原檔**(路徑存在;不搬、不刪) | 缺原檔 → RED |
| Q3 | K 個組**剛好蓋滿** N 個且**不重複**(聯集 = N,兩兩交集 = ∅) | 漏或重疊 → RED |
| Q4 | 全景報告把它們一律標成 **HOLD**(不畫綠、不畫紅) | 報告任何格把隔離項畫成綠 → 本技能自己 RED |

規則:
- `quarantine.json` 裡的 `called: false` 是**聲明**,不是執行期的鎖。本技能讀它、核它、**不改它**;不為了讓某組變綠把 `called` 改成 `true`。
- 為什麼分析器不能進全景(全景只要**計數和路徑**):
  - `ast`、`ruff` 雖然只讀,一呼叫就**擴大這次的讀取面**(把整份原始碼送進另一個分析器)→ 本技能只在 `--static` 用標準庫 `ast`,且不回原文。
  - `black`、`mutmut` **會動檔**;`pytest`、`hypothesis` **會跑程式**、會寫 `.coverage`;`semgrep` **會下載規則**、報告含程式正文。
  - 要資料或網路(讀真實資料列、發請求)的一律不掛;不准為了過檢查去連外。
  - 非此行程的東西(rayon、Send、Sync…)不在這個 Python 行程裡;硬叫只會得到一張**假綠**。
- 有做到 / 沒做到(照實寫進報告「邊界」段):

| 有做到 | 沒做到 |
|---|---|
| 全景路徑不呼叫隔離區 | 沒有禁止 `import engines.<x>` |
| 檔留在原位,健康檢查仍看得到 | 沒有搬到別的目錄或別的使用者 |
| 組和鎖的名單必須一致,否則鎖變紅 | 沒有攔截磁碟寫入、網路、子行程 |
| 報告不把 HOLD 畫成綠 | **名冊不能代替權限** |

要維持這個邊界,就不要從全景、收尾或右欄去呼叫隔離區,也不要為了讓某組變綠而把 `called` 改成 `true`。

## 檔路徑(profile `via-verb-engine` 的預設;其他專案在自己的 profile 指定)

| 件 | 路徑 |
|---|---|
| 隔離區名冊(五組) | `verb-engine/ssot/quarantine.json` |
| 鎖 | `verb-engine/ssot/lock.json` |
| 既有全景檢查(參考,不呼叫) | `verb-engine/engines/VIA_PanoramaCheck.py` |
| 倉 | `tonykuni/VIA-VERB-ENGINE`(main,提交 `2fddc85`;操作員已核本機與遠端三檔都在) |

通用 schema(profile 可改鍵名):`quarantine.json = { "groups": { "<組名>": ["<引擎名>", ...] }, "called": false }`;
`lock.json = { "names": ["<引擎名>", ...] }` 或 `{ "<引擎名>": {"path": "..."} }`。讀不到就 ABSENT,不猜。

Q2 的「原檔」判定:鎖裡有 `path` 就看該路徑;否則檔名主幹或所在夾名等於引擎名;或 profile `file_globs`(`{name}` 代入)命中。
