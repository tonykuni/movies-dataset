# 全景動作字典(Action Matrix;偵測用,不是修復用)

沿用 AST-Sandbox 的動作分級,但本技能**只做「會落在哪一級」的判定與計數**,不執行任何一級的修復。

| 代碼 | 名稱 | 本技能做什麼(只讀) | 產出欄位 | 引擎落點 |
|---|---|---|---|---|
| **AST-OP-100** | 拓樸快照 | 盤點檔案:語言別、檔數、位元組、版本家族(`_v\d{3,4}` 尾版 / 非尾版)、逐位元重複(sha256)、超大檔、符號連結、無法讀取 | 家族 × 尾版 × 舊版數 · 重複群數 · 略過原因計數 | A 段 · B 段 |
| **AST-OP-200** | 靜態合規 | Tier-0:文字標記存在與否(例如模板章標記、加速橋標記、`param(` 是否首句、docstring 首行)。Tier-1(`--static`):`ast.parse` 語法錯計數、定義樹計數(class/def)、`compile` 失敗計數 | 檔 · 標記 · 命中/缺 · 行號 | C 段 |
| **AST-OP-300** | 無損注入候選 | 只列「缺標記但可注入」的檔數與路徑;**不注入** | 候選清單(路徑) | F 段 `op300` |
| **AST-OP-400** | 同質批次候選 | 只列同一型錯誤跨檔重複的群組(以錯誤簽名分群);**不替換** | 簽名 → 檔數 | F 段 `op400` |
| **AST-OP-500** | 順序重構隔離 | 只列跨模組 / 循環依賴 / 無法分類的項,打包成最精簡上下文(路徑 + 行號 + 一行簽名,**無原文**)供人或 LLM 第二輪決策 | 隔離清單 + 濃縮包 | F 段 `op500_pack` |
| **RATCHET** | 棘輪防退步 | 讀本技能自己的 `universal_ledger.jsonl` 前一筆:紅燈數今 > 昨 = **RETROGRESS**(報告亮紅,結束碼 1);沒有前一筆 = `NODATA`(不算退步也不算過關) | 昨 / 今 / 差 | G 段 |

## 引擎實作上的判定細節

- **尾版**:同夾 · 同家族 · 同副檔名取最大版號;標記只查尾版(版史不算)。沒有版號的檔自己就是尾版。
- **HOLD**(不計缺、不畫綠):隔離區名冊的名字 · 逐檔凍結(`<檔>.freeze.lock.json` 只凍該檔)· profile `readonly_rosters` 名冊內的檔 · 標記的 `exempt_names` / `exempt_name_regex`。
- **簽名分群**(OP-400/500):簽名裡的數字正規化成 `N` 再分群;≥ 2 檔 = OP-400,單發 = OP-500。
- **PINVER**(OP-500 來源之一):`import` / `from` 敘述硬匯入某家族的舊版號,而樹上有更新的尾版。
- **紅數**(棘輪用):C 段 RED 標記的缺數 + D 段 RED 列數 + E 段本機缺的尾版族數。
- 常見假陽性已處理:docstring 裡的 `import` 字樣、函式內的 `param(`、`<# … #>` 說明區塊、UTF-8 BOM、提交進倉的虛擬環境(`pyvenv.cfg`)。
