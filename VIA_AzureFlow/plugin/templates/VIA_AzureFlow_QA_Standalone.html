輸入設定

可拖曳 ZIP；Windows 完整路徑請貼入欄位，瀏覽器不會擅自讀取本機完整路徑。

將 VIA ZIP 拖曳到這裡尚未選取 ZIP
verify／all 會傳給 PowerShell launcher；若只用 UI 先產生命令即可。
●瀏覽器 UI 只產生命令，不會自動執行所選檔案。請按「複製命令」後在 PowerShell 執行 `Invoke-VIA-AzureFlowQA.ps1`。
待命：請選擇輸入，或直接按任一動作產生命令。
