Windows 安裝位置

C:\VIA\plugins\via-azureflow-qa-plugin\
  • 先用 SHA-256 sidecar 驗證 ZIP。
  • 用 Expand-Archive 解壓。
  • 用 launcher 或 Scheduled runner 執行。

Task Scheduler 建議

  • Action：`PowerShell.exe`。
  • Arguments：`-NoProfile -NonInteractive -ExecutionPolicy Bypass -File ...`。
  • Start in：Plug-in 根目錄。
  • Output：每次使用 timestamped directory。
  • 保留 `task_scheduler.log`、`task_result.json` 與 combined summary。
