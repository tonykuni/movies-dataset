| 道 | 怎麼用 | 位置 | 複製? |
|---|---|---|---|

| 參數 | `via-vrnin -Path "D:\a.pdf","E:\報告夾"` | 任何位置 | 否,就地讀 |

最後一列不是設計偷懶:瀏覽器的 `webkitdirectory` / `<input type=file>`
**拿不到真實路徑**,只給 `webkitRelativePath`(相對名),所以那條道**必然**是
複製。這句話現在直接寫在頁上,不讓人自己猜。

三個實作坑(都是跑出來才知道的):
- **PS7 預設 MTA** → 對話框 `ShowDialog()` 會拋
  `current thread must be set to single thread apartment`。一律丟進 STA runspace。
- **`.ps1` 收不到拖曳** → 檔案總管拖到 `.ps1` 上只會用記事本開它;`.cmd` 才收得到 `%*`。
- **`$input` 會預讀 stdin 卡死** → 腳本一提 `$input`,PowerShell 在 `-File` 模式
  會先把 stdin 讀到 EOF 才開跑。stdin 是沒人關的管線時,它不是慢,是**永遠不回**
  (自測第一次就這樣掛住)。管線輸入改成只有明講 `-FromPipe` 才讀。

零彈窗律沒有破:對話框**只在操作員自己要求時**開(`-Pick`);
`VIA_NO_DIALOG=1` / CI / 非互動 / 非 Windows 一律不開,改為誠實要求 `-Path`。

## 十、批469 tessdata 中文 —— 引擎側實證 + 簡繁混雜修

### 10.1 唯一變因實驗

在本容器把 `chi_tra` / `chi_sim`(各 13 MB,tessdata_best)裝進
`/usr/share/tesseract-ocr/5/tessdata/`,同一張圖、同一支引擎、同一條道再跑一次:

| | 裝之前 | 裝之後 |
|---|---|---|
| `台積電` | `ARs` | 讀得出來 |
| `買進` | `Bié` | 讀得出來 |
| 字數 | 180 | **240** |
| 第三態警語 `[無中文語言檔…]` | 掛著 | **自動消失** |

**引擎側到此證明是對的** —— 工作站那邊唯一還缺的就是那兩個檔。

### 10.2 但同一跑照出新缺陷:簡繁混雜

裝上之後輸出是 `2330 台积电` / `研究 报告` —— **簡繁混在同一頁**。
tesseract 同時裝了 `chi_sim` 與 `chi_tra` 時,**逐行挑哪一本由它自己決定**。
下游拿這種字去對名冊會**時中時不中**,而錯得沒有規律的那種最難查。

修法(`ENG072 v0116`,二十九檢 29/29):OCR 道的產物過一次 **ENG066 樞紐的
`normalize()`** —— 那正是 ENG067 用來把「联发科→聯發科」收斂的同一支,
**不另寫轉換表**(Zero-Hydra)。

- **只對 OCR 道**:PDF 文字層是文件自己寫的字,不該被我改寫。
- 樞紐缺席 → 原樣輸出並在 tag 標 `[未繁化:因由]`,**不假裝做過**。

自審:第一版我以為 `_nlp_tp().normalize()` 會繁化 —— **實測不會**
(`台积电` 進去 `台积电` 出來)。是 ENG066 樞紐的 `normalize()` 才會。
名字像不等於語意像,這是同一課第二次。

最終輸出(`tag=[繁化]`,240 字):

> 2330 臺積電 買進 (Buy) 目標價 NT$1,250 元 研究報告 2026/09/11
> 投資評等:買進(維持)前次評等:買進 目標價:1,250 元(原 1,180 元)
> 收盤價:1,065 元 2026 年 EPS 預估 59.8 元,本益比 17.8 倍。
> 我們預期 2027 年營收年增 22%,毛利率 58.5%。風險:匯率波動、先進製程遞延

(輸出用「臺積電」;台↔臺 的正字漂移 `MDL142._alt_forms` 已涵蓋,對名冊照樣命中。)
