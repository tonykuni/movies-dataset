# AI Agent 應用一覽 — 金融十式(業務/顧問 × 研究/建模 × 基金行政 × 營運/開戶)

> 來源:對話筆記彙整(2026-08-26),原文引用標記已清除。
> 十個 agent 依四大業務面分類,聚焦投行/PE/基金營運中可交由 agent 代理的工作流。

## 一、應用總表

| 分類 | Agent | 做什麼 |
|------|-------|--------|
| 業務/顧問 | **Pitch Agent** | Comps、precedents、LBO → 品牌化 pitch deck |
| | **Meeting Prep Agent** | 客戶會議前的簡報包 |
| 研究/建模 | **Market Researcher** | 產業或主題 → 產業概覽、競爭格局、peer comps、標的清單 |
| | **Earnings Reviewer** | 法說會＋財報 → 更新模型 → 研究報告初稿 |
| | **Model Builder** | DCF、LBO、三表、comps,直接在 Excel 內跑 |
| 基金行政 | **Valuation Reviewer** | 吃 GP 資料包、跑評價模板、備妥 LP 報告 |
| | **GL Reconciler** | 找帳差、追根因、送審 |
| | **Month-End Closer** | 應計、roll-forward、差異說明 |
| | **Statement Auditor** | LP 對帳單發送前稽核 |
| 營運/開戶 | **KYC Screener** | 解析開戶文件、跑規則引擎、標出缺漏 |

## 二、分類速覽

- **業務/顧問(前台)**:2 式 — pitch 產製與會前準備,產出直接面向客戶。
- **研究/建模**:3 式 — 從產業研究到財報更新到 Excel 內建模,覆蓋研究員全鏈。
- **基金行政(後台)**:4 式 — 評價、對帳、月結、對帳單稽核,規則明確、重複性高,最適合 agent 化。
- **營運/開戶**:1 式 — KYC 文件解析與規則引擎篩查。
